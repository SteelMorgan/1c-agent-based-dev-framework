# Быстрая установка в проекты

Когда пользователь просит установить/обновить навыки/скилы/правила/rules/skills в проект — запусти соответствующий скрипт.

| Алиасы пользователя | Проект | Скрипт |
|----------------------|--------|--------|
| драйв, drive | DSSL DRIVE | `python3 tools/fast-install/install-drive.py` |
| ут, ut | DSSL UT | `python3 tools/fast-install/install-ut.py` |
| гбиг, gbig, pam, пам | GBIG PAM | `python3 tools/fast-install/install-pam.py` |

Триггерные фразы: «установи в …», «обнови скилы в …», «обнови навыки в …», «обнови правила в …», «залей в …», «закинь в …», «поставь в …».

Если пользователь не указал конкретный проект — установить во **все три**.

## «Обнови всё» / «обнови все проекты» / «залей везде»

Запустить **все** `*.py` скрипты из `tools/fast-install/` параллельно. Каталог может содержать больше скриптов, чем перечислено в таблице выше — запускать все найденные.
