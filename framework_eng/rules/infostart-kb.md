# Infostart Knowledge Base (before 1C development)

> **Trigger:** before writing, debugging, or designing 1C:Enterprise code (documents, registers, БСП, managed forms, extensions, queries, exchange, etc.). When triggered, apply the `infostart-kb` skill (`framework/skills/other/infostart-kb/SKILL.md`).

The knowledge base contains hundreds of thousands of real solutions and known community issues - using it for 1C tasks is mandatory. Call `find_solution` / `how_to` / `troubleshoot` before writing code, and after that - `report_result`.
