## Windows

```gherkin
открылось окно "Название окна"

```

## Form fields

```gherkin
в поле с именем "ИмяПоля" я ввожу текст "Значение"
В открытой форме в поле с именем "ИмяПоля" я ввожу текст "Значение"
я перехожу к следующему реквизиту
элемент формы "ИмяПоля" стал равен "Значение"
```

**Name vs field title (important):**
- `in field with name "Name"` / `in field "Name"` — search by **programmatic name** of the element (`name`).
- `in field with title "Title"` — search by **visible title** (`Title`).
- The visible title can be **truncated/incomplete**, so **prefer the name** (`in field with name` / `in field`); use the “with title” step **only if you cannot determine the field's programmatic name**.

## Tables (ТЧ)

```gherkin
# Навигация к строке по одной или нескольким колонкам
в таблице "List" я перехожу к строке:
    | 'Номер'   |
    | 'ДОК-001' |

В форме "Форма" в таблице "List" я перехожу к строке:
    | 'Код'   | 'Наименование' |
    | '00001' | 'Элемент1'     |

# Выбрать строку (двойной клик)
в таблице "List" я выбираю текущую строку
В форме "Форма" в ТЧ "List" я выбираю текущую строку

# Ввод в ячейку ТЧ
В ТЧ "Inventory" в поле "% скидки" я ввожу текст 5
В форме "Форма" в ТЧ "ТЧ" в поле с заголовком "Поле" я ввожу текст "Значение"

# Завершить редактирование строки
В форме "Форма" в ТЧ "Inventory" я завершаю редактирование строки

# Количество строк
в таблице "List" 0 строк
в таблице "List" 3 строки
в таблице "List" больше 0 строк
в таблице "List" меньше или равно 5 строк

# Содержимое таблицы
таблица "List" содержит строки:
    | N | Колонка1  |
    | 1 | Значение1 |

таблица "List" стала равной:
    | N | Колонка1  |
    | 1 | Значение1 |
```
