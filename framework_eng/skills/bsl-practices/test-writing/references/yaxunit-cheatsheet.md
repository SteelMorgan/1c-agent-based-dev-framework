# YaxUnit — API Reference

> Source: https://github.com/bia-technologies/yaxunit/tree/develop/documentation/docs/features

---

## Entry Points

| Module | Purpose |
|--------|---------|
| `ЮТТесты` | Register tests in `ИсполняемыеСценарии` |
| `ЮТест` | API entry point inside tests |
| `ЮТест.ОжидаетЧто(...)` | → Assertions module `ЮТУтверждения` |
| `ЮТест.ОжидаетЧтоТаблицаБазы(...)` | → Database assertions `ЮТУтвержденияИБ` |
| `ЮТест.Данные()` | → Test data `ЮТТестовыеДанные` |
| `ЮТест.Контекст()` | → Test context `ЮТКонтекстТеста` |
| `ЮТест.Предикат()` | → Predicate builder `ЮТПредикаты` |
| `ЮТест.Варианты()` | → Parameterization variants builder |
| `Мокито` | Mocking configuration methods |

## ЮТТесты — Registration

```bsl
ЮТТесты
    .ДобавитьТестовыйНабор("Имя набора")           // группировка тестов
        .ДобавитьТест("ИмяПроцедуры")              // дефолтный контекст
        .ДобавитьСерверныйТест("ИмяПроцедуры")     // &НаСервереБезКонтекста
        .ДобавитьКлиентскийТест("ИмяПроцедуры")    // &НаКлиенте
        .СПараметрами(Варианты)                     // параметризация
        .СПараметрамиНаКлиенте(Варианты)
        .СПараметрамиНаСервере(Варианты)
        .Тег("ИмяТега")                             // фильтрация при запуске
        .ВТранзакции()                              // откат данных после теста
        .УдалениеТестовыхДанных()                   // автоочистка через ЮТест.Данные
        .Перед("ИмяПроцедуры")                      // обработчик перед набором/тестом
        .После("ИмяПроцедуры")                      // обработчик после набора/теста
        .Зависит("ИмяДругогоТеста")                // зависимость от другого теста
        .СвойствоОтчета("ключ", "значение")        // метаданные для JUnit/Allure
        .ЮТАлюр()                                   // цепочка Allure-аннотаций
```

## ЮТУтверждения — Basic Assertions

All methods return `ЭтотОбъект` — chains are supported.

### Value Comparison
```bsl
.Равно(ОжидаемоеЗначение)
.НеРавно(НеОжидаемоеЗначение)
.Больше(Граница)
.БольшеИлиРавно(Граница)
.Меньше(Граница)
.МеньшеИлиРавно(Граница)
```

### Boolean
```bsl
.ЭтоИстина()
.ЭтоЛожь()
.ЭтоНеИстина()
.ЭтоНеЛожь()
```

### Type and Completeness
```bsl
.ИмеетТип("ИмяТипа")           // строка: "Число", "СправочникСсылка.Номенклатура"
.НеЯвляетсяНеопределено()
.ЯвляетсяНеопределено()
.НеПусто()                      // строка/коллекция/ссылка не пустая
.Пусто()
```

### Collections and Strings
```bsl
.ВСписке(Массив)                // значение входит в список
.НеВСписке(Массив)
.СодержитСтроку(Подстрока)      // для строк
.НачинаетсяС(Префикс)
.ЗаканчиваетсяНа(Суффикс)
```

### Exceptions
```bsl
.МетодВыбрасываетИсключение("ИмяМетода", МассивПараметров)
.МетодВыбрасываетИсключение("ИмяМетода", МассивПараметров, "ТекстИсключения")
```

### Utility
```bsl
.НазваниеПроверки("Описание")   // добавить имя к утверждению (для параметризации)
```

## ЮТУтвержденияИБ — Assertions for Database

```bsl
ЮТест.ОжидаетЧтоТаблицаБазы("Справочник.Склады")
    .СодержитЗаписи()
    .НеСодержитЗаписей()
    .КоличествоЗаписей(N)
    .ГдеРеквизит("Наименование").Равно("Основной")
    .ГдеРеквизит("Код").НеРавно("")
    .ГдеРеквизит("ПометкаУдаления").ЭтоЛожь()
```

## ЮТТестовыеДанные — Data Creation

### Placeholders (minimal data fill)
```bsl
ЮТест.Данные().СоздатьЭлемент("Справочник.Номенклатура")     // → Ссылка
ЮТест.Данные().СоздатьГруппу("Справочник.Номенклатура")      // → Ссылка (группа)
ЮТест.Данные().СоздатьДокумент("Документ.ПоступлениеТоваров") // → Ссылка
```

### Object Builder
```bsl
ЮТест.Данные()
    .КонструкторОбъекта("Справочник.Номенклатура")
    .Установить("Наименование", "Тестовый товар")
    .Установить("Артикул", "ART-001")
    .УстановитьТабличнуюЧасть("Аналоги")          // переключиться на ТЧ
        .ДобавитьСтроку()
        .Установить("Номенклатура", ДругаяСсылка)
    .Записать()
    .Ссылка()                                       // → СправочникСсылка
```

### Modifying Existing Objects
```bsl
ЮТест.Данные().УстановитьЗначениеРеквизита(Ссылка, "Реквизит", Значение)
ЮТест.Данные().УстановитьЗначенияРеквизитов(Ссылка, Структура)
```

### Miscellaneous
```bsl
ЮТест.Данные().КонструкторОбъектаXDTO(ИмяПакета, ИмяТипа)
ЮТест.Данные().HTTPСервисЗапрос()    // эмуляция входящего HTTP-запроса
ЮТест.Данные().ADORecordSet()        // эмуляция ADO.RecordSet
```

## ЮТКонтекстТеста — Passing Data

```bsl
// Записать
ЮТест.Контекст().УстановитьЗначение("Ключ", Данные)

// Прочитать (ищет вверх по иерархии: тест → набор → модуль)
Данные = ЮТест.Контекст().Значение("Ключ")
```

**Context scopes:**
- Test context — available in `ПередКаждымТестом` and `ПослеКаждогоТеста`
- Suite context — available to all tests in the suite
- Module context — available to all tests in the module (`ПередВсемиТестами` / `ПослеВсехТестов`)

## Mockito

```bsl
// Обучение
Мокито.Обучение(ОбщийМодуль)
    .Когда().МетодА(Арг1, Арг2).Вернуть(Значение)
    .Когда().МетодБ().ВыброситьИсключение("Текст")
    .Когда().МетодВ().Пропустить()
    .Когда().МетодГ().Наблюдать()

// Проверка вызовов
Мокито.Проверить(ОбщийМодуль)
    .МетодА(Арг1, Арг2)           // был ли вызван с этими аргументами
```

**Limitation:** Mockito only works with **exported methods of common modules**.

## ЮТест helper methods

```bsl
ЮТест.Пропустить()                          // пропустить тест (skip)
ЮТест.Упал("Сообщение")                     // явное падение теста
ЮТест.Упал("Сообщение", Ожидалось, Факт)    // с деталями сравнения
ЮТест.Пауза(МиллисекундыИлиСекунды)
ЮТест.ВывестиВКонсоль(Значение)
```

## Predicates (ЮТест.Предикат)

Used for complex conditions in assertions:

```bsl
Предикат = ЮТест.Предикат()
    .Реквизит("Количество").Больше(0)
    .Реквизит("Наименование").НеПусто();

ЮТест.ОжидаетЧто(Объект).СоответствуетПредикату(Предикат);
```

## Lifecycle Events

| Event | When | Context |
|-------|------|---------|
| `ПередВсемиТестами` | Before the first test of the module | Module context |
| `ПередТестовымНабором` | Before the first test of the suite | Suite context |
| `ПередКаждымТестом` | Before each test | Test context |
| `ПослеКаждогоТеста` | After each test | Test context |
| `ПослеТестовогоНабора` | After the last test of the suite | Suite context |
| `ПослеВсехТестов` | After the last test of the module | Module context |

## Naming

| Object | Recommendation |
|--------|----------------|
| Test module | `Тесты` + the name of the module under test: `ТестыУправлениеСкладом` |
| Test procedure | `Тест` + scenario description: `ТестПолучитьОстатокПустойСклад` |
| Test suite | Group by functionality: `"Остатки"`, `"Перемещение"` |
