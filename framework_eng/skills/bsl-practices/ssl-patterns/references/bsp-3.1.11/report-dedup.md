# Duplicate search, bulk modification, and BSP subordination structure

Three related subsystems for **mass data processing**:
**ПоискИУдалениеДублей** (programmatic and interactive search for identical
items, fuzzy string comparison, merge, reference replacement),
**ГрупповоеИзменениеОбъектов** (the "Change selected" command in list forms,
bulk processing of attributes) and **СтруктураПодчиненности** (the "Related
documents" report - a tree of parent and child objects by reference). The
subsystems are linked through the `ГрупповоеИзменениеРеквизитов` processing and
the mechanism of attached commands.

## Modules

- `ПоискИУдалениеДублей` — server API: programmatic duplicate search, fuzzy
  string comparison, validation and execution of reference replacement.
- `ПоискИУдалениеДублейКлиент` — client API: merge forms, replacement forms,
  usage locations.
- `ПоискИУдалениеДублейПереопределяемый` — hooks: which objects participate in
  the search, application-specific rules, whitelist of methods for a "custom algorithm".
- `ГрупповоеИзменениеОбъектовКлиент` — client API: `ИзменитьВыделенные`.
- `ГрупповоеИзменениеОбъектов` — server module with methods
  `ПриОпределенииВидовПодключаемыхКоманд` / `ПриОпределениеКомандПодключенныхКОбъекту`
  (called by BSP automatically when attaching commands to forms).
- `ГрупповоеИзменениеОбъектовПереопределяемый` — hooks: in which forms to show
  the "Change selected" command, the set of editable attributes.
- `СтруктураПодчиненностиПереопределяемый` — **the only** module of the subsystem
  "Subordination structure"; all methods are override hooks. The report itself
  `Связанные документы` (`Отчет.СвязанныеДокументы`) is generated by BSP via the
  link on the navigation panel/command; there is no stable programmatic API for
  generating the report - only hooks for influencing the output.

⚠️ The subsystems `ПоискИУдалениеДублей` and `ГрупповоеИзменениеОбъектов` **do not have**
modules with the suffixes `Служебный` / `ВызовСервера` / `ПовтИсп` / `Глобальный` -
service methods are built into the main modules under the sections
`СлужебныйПрограммныйИнтерфейс` / `СлужебныеПроцедурыИФункции`.

⚠️ Common mistakes:
- `СтруктураПодчиненности` (without `Переопределяемый`) — the module **does not exist**.
  Only `СтруктураПодчиненностиПереопределяемый` (hooks).
- For reference replacement, the stable API is `ОбщегоНазначения.ЗаменитьСсылки` (see
  `base-common.md`), not the service `ПоискИУдалениеДублей.ЗаменитьСсылки`.

## Scenarios

### 1. Programmatic search for duplicate elements

**Task:** find all elements of a catalog/chart of accounts/chart of characteristic types that are similar to the reference item, before merging or for a report.

**Function:**
`ПоискИУдалениеДублей.НайтиДублиЭлемента(Знач ОбластьПоиска, Знач ЭталонныйОбъект, Знач ДополнительныеПараметры) Экспорт`
— Function → `ТаблицаЗначений` (columns `Ссылка`, `Код`, `Наименование`,
  `Родитель`, `ДругиеПоля`), region `#Область ПрограммныйИнтерфейс` (stable).
  Server.

**Parameters:**
- `ОбластьПоиска` (String) — the full metadata name of the search area, for example
  `"Справочник.Номенклатура"`. Catalogs, charts of characteristic types,
  calculation types, and charts of accounts are supported.
- `ЭталонныйОбъект` (AnyRef / СправочникОбъект) — the item for which
  duplicates are searched.
- `ДополнительныеПараметры` (Arbitrary) — a parameter passed to the manager
  event handlers (`ПриОпределенииПараметровПоискаДублей`,
  `ПриПоискеДублей`).

**Example:**
```bsl
Эталон = Справочники.Номенклатура.НайтиПоНаименованию("Стол обеденный");
Если Эталон.Пустая() Тогда
    Возврат;
КонецЕсли;

Дубли = ПоискИУдалениеДублей.НайтиДублиЭлемента(
    "Справочник.Номенклатура", Эталон, Неопределено);

ПарыЗамен = Новый Соответствие;
Для Каждого СтрокаДубля Из Дубли Цикл
    Если СтрокаДубля.Ссылка = Эталон Тогда
        Продолжить;  // skip the reference item itself
    КонецЕсли;
    ПарыЗамен.Вставить(СтрокаДубля.Ссылка, Эталон);
КонецЦикла;
```

**Nuances / anti-patterns:**
- The method builds the data composition schema itself based on the available attributes, initializes
  `КомпоновщикПредварительногоОтбора` and, through the `ПоискИУдалениеДублей` processing, obtains duplicate groups.
  It takes application rules into account
  (`ПоискИУдалениеДублейПереопределяемый.ПриОпределенииПараметровПоискаДублей`)
  and post-processing (`ПриПоискеДублей`).
- `Родитель` is empty for the parent item of the duplicate group; for the duplicates themselves, it is
  a reference to the group parent.
- ❌ Searching for duplicates with a direct query using `ГДЕ Наименование = …` does not account for
  fuzzy matches and application search rules. Use
  `НайтиДублиЭлемента`.

### 2. Fuzzy search for similar strings (Levenshtein-Damerau)

**Task:** find in an array of strings those that are similar to a given one (typos,
different word order), with a configurable match threshold and a list of
exception words (`ООО`, `ИП`).

**Functions:**
`ПоискИУдалениеДублей.НайтиПохожиеСтроки(ИсходнаяСтрока, СтрокаПоиска, Разделитель = "~", ПараметрыПоиска = Неопределено) Экспорт`
— Function → `Строка` (indices of similar strings separated by commas, numbering starts from `0`),
  region `#Область ПрограммныйИнтерфейс` (stable). Server.
`ПоискИУдалениеДублей.ПараметрыПоискаПохожихСтрок(ПодключитьКомпоненту = Истина) Экспорт`
— Function → `Структура` (`ПроцентСовпаденияСтрок` = 90,
  `ПроцентСовпаденияНебольшихСтрок` = 80, `ДлинаНебольшихСтрок` = 30,
  `СловаИсключения` — Array, `КомпонентаПоиска` — external component object
  `FuzzyStringMatchExtension`). Server.

**Parameters:**
- `ИсходнаяСтрока` (String) — a set of strings separated by `Разделитель`, in which
  we search.
- `СтрокаПоиска` (String) — the string whose occurrence we search for.
- `Разделитель` (String) — separator character in `ИсходнаяСтрока`; `"~"` by
  default.
- `ПараметрыПоиска` (Structure) — from `ПараметрыПоискаПохожихСтрок`;
  `Неопределено` — the method will obtain the parameters itself (with component connection).
- `ПодключитьКомпоненту` (Boolean) — `Истина` (default) — connect
  the external search component and return it in `КомпонентаПоиска`; `Ложь` — if
  the component is already connected higher up the stack.

**Example:**
```bsl
// Optimization for bulk calls: get the parameters with the component once
Параметры = ПоискИУдалениеДублей.ПараметрыПоискаПохожихСтрок();  // ПодключитьКомпоненту = Истина

ИсходнаяСтрока = "Токарный станок~Вентилятор настольный~Стол обеденный~Стул обеденный";
Для Каждого Запрос Из МассивЗапросов Цикл
    Индексы = ПоискИУдалениеДублей.НайтиПохожиеСтроки(ИсходнаяСтрока, Запрос, "~", Параметры);
    // E.g. for "Стол обеденный" -> "2,3" (indices of "Стол обеденный" and "Стул обеденный")
КонецЦикла;
```

**Nuances / anti-patterns:**
- ❌ Call `НайтиПохожиеСтроки` in a loop **without** `ПараметрыПоиска` — every
  call reconnects the external component from scratch (expensive). Get the parameters once via `ПараметрыПоискаПохожихСтрок()` and pass them into the loop.
- `ПараметрыПоискаПохожихСтрок(Ложь)` — a valid scenario if the component is already
  connected somewhere higher up; it returns a structure without reconnecting.
- The algorithm ignores case and word order; `СловаИсключения` (`"ООО"`,
  `"ИП"`, `"ОАО"`) are excluded from comparison.

### 3. Replace references across the entire IB

**Task:** programmatically replace one item with another everywhere it is used (documents, registers, attributes), with marking/deletion of the duplicate and control over applied replacement rules.

**Functions:**
`ОбщегоНазначения.ЗаменитьСсылки(Знач ПарыЗамен, Знач ПараметрыЗамены = Неопределено) Экспорт`
— Function → `ТаблицаЗначений` of errors (columns `Ссылка`, `ОбъектОшибки`,
  `ТипОшибки`, `ИнформацияОбОшибке`, `ТекстОшибки`), region
  `#Область ПрограммныйИнтерфейс` (stable). Server. **This is the stable
  recommended path.**
`ОбщегоНазначения.ПараметрыЗаменыСсылок() Экспорт`
— constructor of the `ПараметрыЗамены` structure (`СпособУдаления` = `""` /
  `"Пометка"` / `"Непосредственно"`; `УчитыватьПрикладныеПравила` — Boolean;
  `ВключатьБизнесЛогику` — Boolean). Server.
`ПоискИУдалениеДублей.ПроверитьВозможностьЗаменыЭлементов(ПарыЗамен, ПараметрыЗамены) Экспорт`
— Function → `Соответствие` of errors (empty if replacement is allowed); ⚠️
  `СлужебныйПрограммныйИнтерфейс`. Queries `ВозможностьЗаменыЭлементов`
  of the object manager module and
  `ПоискИУдалениеДублейПереопределяемый.ПриОпределенииВозможностиЗаменыЭлементов`.
  Server.
`ПоискИУдалениеДублей.ДополнитьДублиСвязаннымиПодчиненнымиОбъектами(ПарыЗамен, ПараметрыЗамены) Экспорт`
— Procedure, region `#Область ПрограммныйИнтерфейс` (stable). Completes
  `ПарыЗамен` with related subordinate objects (for example, when replacing
  a counterparty, replace its bank account as well). Server.
`ПоискИУдалениеДублей.ЗаменитьСсылки(Параметры, Знач АдресРезультата) Экспорт`
— Procedure, ⚠️ `СлужебныеПроцедурыИФункции`. Server. Wrapper over
  `ОбщегоНазначения.ЗаменитьСсылки` with forced
  `ВключатьБизнесЛогику = Истина`; the result (table of errors) is placed in
  `АдресРезультата` (temporary storage) — for running in a background job.

**Parameters:**
- `ПарыЗамен` (Соответствие) — `Key` = what is replaced (duplicate, `ЛюбаяСсылка`),
  `Value` = what it is replaced with (original). Self-references and empty ones are ignored.
- `ПараметрыЗамены` (Structure) — from `ПараметрыЗаменыСсылок()`:
  - `СпособУдаления` (String): `""` — do not touch the duplicate; `"Пометка"` — mark
    for deletion; `"Непосредственно"` — delete.
  - `УчитыватьПрикладныеПравила` (Boolean): `Истина` — for each pair
    `ВозможностьЗаменыЭлементов` of the manager module is called (requires the subsystem
    “Поиск и удаление дублей”); `Ложь` by default.
  - `ВключатьБизнесЛогику` (Boolean): `Истина` (by default) — places
    of use are recorded in normal mode; `Ложь` — in the mode
    `ОбменДанными.Загрузка = Истина` (without reposting).

**Example:**
```bsl
ПарыЗамен = Новый Соответствие;
ПарыЗамен.Вставить(ДублирующийЭлемент, ОригинальныйЭлемент);

ПараметрыЗамены = ОбщегоНазначения.ПараметрыЗаменыСсылок();
ПараметрыЗамены.СпособУдаления = "Пометка";
ПараметрыЗамены.УчитыватьПрикладныеПравила = Истина;  // проверка ВозможностьЗаменыЭлементов

// 1) Check admissibility (applied rules: prohibiting changing currency in posted documents, etc.)
Ошибки = ПоискИУдалениеДублей.ПроверитьВозможностьЗаменыЭлементов(ПарыЗамен, ПараметрыЗамены);
Если Ошибки.Количество() > 0 Тогда
    // ...output errors via ОбщегоНазначения.СообщитьПользователю
    Возврат;
КонецЕсли;

// 2) Complete with related subordinate objects (bank account, analytics keys)
ПоискИУдалениеДублей.ДополнитьДублиСвязаннымиПодчиненнымиОбъектами(ПарыЗамен, ПараметрыЗамены);

// 3) Perform replacement (stable API returns the error table directly)
ОшибкиЗамены = ОбщегоНазначения.ЗаменитьСсылки(ПарыЗамен, ПараметрыЗамены);
```

**Nuances / anti-patterns:**
- ❌ Calling `ПоискИУдалениеДублей.ЗаменитьСсылки` as the primary path is
  ⚠️ a service method (`СлужебныеПроцедурыИФункции`), backward compatibility is not
  guaranteed. The stable API is `ОбщегоНазначения.ЗаменитьСсылки`.
  The service variant is needed only to run in a background job when the
  result must be placed in temporary storage by `АдресРезультата` (see
  `longs-and-jobs.md`, long-running operations).
- ❌ Running `ЗаменитьСсылки` without `ПроверитьВозможностьЗаменыЭлементов`
  (when `УчитыватьПрикладныеПравила = Истина`) means the replacement will bypass application
  rules (prohibition on changing currency in posted documents, prohibition on changing
  the organization in a closed period). First validate, then replace.
- Replacement happens **with transactions for the modified object and its relations**, not
  for the analyzed reference. When called in a non-separate session, references in
  separate areas are not detected.
- To run replacement in the background with progress and cancellation, wrap the call through
  `ДлительныеОперации` (see `longs-and-jobs.md`).

### 4. Commands for merge, replace, and usage locations in a list form

**Task:** in a list form, add the commands “Merge selected”,
“Replace selected”, “Usage locations” (through connected
command handlers).

**Functions:**
`ПоискИУдалениеДублейКлиент.ОбъединитьВыделенные(Знач ОбъединяемыеЭлементы, ДополнительныеПараметры = Неопределено) Экспорт`
— opens the element merge wizard form. Client.
`ПоискИУдалениеДублейКлиент.ЗаменитьВыделенные(Знач ЗаменяемыеЭлементы, ДополнительныеПараметры = Неопределено) Экспорт`
— opens the replace and delete form. Client.
`ПоискИУдалениеДублейКлиент.ПоказатьМестаИспользования(Знач Элементы, Знач ПараметрыОткрытия = Неопределено) Экспорт`
— opens the `МестаИспользованияСсылок` report filtered by the passed references;
  auxiliary data (record sets with a leading dimension) are **not
  included**. Client.
— all Procedures, region `#Область ПрограммныйИнтерфейс` (stable).

**Parameters:**
- `ОбъединяемыеЭлементы` / `ЗаменяемыеЭлементы` (`ТаблицаФормы` / `Массив из
  ЛюбаяСсылка` / `СписокЗначений` with the `Ссылка` attribute) — the selected list
  items.
- `Элементы` (same type) — references for the usage locations report.
- `ПараметрыОткрытия` (Structure) — optional report form opening parameters.

**Example:**
```bsl
// Form module of the catalog list
&НаКлиенте
Процедура Подключаемый_ОбъединитьВыделенные(Команда)
    ПоискИУдалениеДублейКлиент.ОбъединитьВыделенные(Элементы.Список);
КонецПроцедуры

&НаКлиенте
Процедура Подключаемый_ЗаменитьВыделенные(Команда)
    ПоискИУдалениеДублейКлиент.ЗаменитьВыделенные(Элементы.Список);
КонецПроцедуры

&НаКлиенте
Процедура Подключаемый_ПоказатьМестаИспользования(Команда)
    ПоискИУдалениеДублейКлиент.ПоказатьМестаИспользования(Элементы.Список);
КонецПроцедуры
```

**Nuances / anti-patterns:**
- ❌ Adding these buttons to the form manually when the `ПодключаемыеКоманды`
  subsystem is connected is duplication. Connected commands already add them
  automatically through
  `ПоискИУдалениеДублей.ПриОпределенииКомандПодключенныхКОбъекту` (⚠️
  `СлужебныйПрограммныйИнтерфейс`, called by БСП). If `ПодключаемыеКоманды`
  are not used, add the buttons manually as in the example.
- `ОбъединитьВыделенные` opens the attribute mapping wizard;
  the user confirms the replacement. `ЗаменитьВыделенные` opens the form for choosing new
  values and marking/deleting the original ones.

### 5. Command "Edit Selected" and restriction of editable attributes

**Task:** in the list form, add a command for bulk editing attributes and
restrict the set of attributes available for bulk editing of a specific object
(for example, prohibit mass changes to a counterparty's `ИНН`/`КПП`).

**Function:**
`ГрупповоеИзменениеОбъектовКлиент.ИзменитьВыделенные(СписокЭлемент, Знач СписокРеквизит = Неопределено) Экспорт`
— Procedure, opens the `Обработка.ГрупповоеИзменениеРеквизитов` form for
the selected rows. Region `#Область ПрограммныйИнтерфейс` (stable). Client.

**Parameters:**
- `СписокЭлемент` (`ТаблицаФормы` / `Массив из ЛюбаяСсылка`) — form element with
the list.
- `СписокРеквизит` (`ДинамическийСписок`) — form attribute with the list;
  optional, for passing a filter.

**Example:**
```bsl
&НаКлиенте
Процедура Подключаемый_ИзменитьВыделенные(Команда)
    // Check the "Изменение" right before opening the form
    Если Не ПравоДоступа("Изменение", Метаданные.Справочники.Контрагенты) Тогда
        Возврат;
    КонецЕсли;

    // Check that there are no items marked for deletion among the selected ones
    МожноРедактировать = Истина;
    Для Каждого ВыделеннаяСтрока Из Элементы.Список.ВыделенныеСтроки Цикл
        ТекДанные = Элементы.Список.ДанныеСтроки(ВыделеннаяСтрока);
        Если ТекДанные <> Неопределено И Не ТекДанные.Ссылка.Пустая()
            И ТекДанные.Ссылка.ПометкаУдаления Тогда
            МожноРедактировать = Ложь;
            Прервать;
        КонецЕсли;
    КонецЦикла;

    Если МожноРедактировать Тогда
        ГрупповоеИзменениеОбъектовКлиент.ИзменитьВыделенные(Элементы.Список, Список);
    КонецЕсли;
КонецПроцедуры
```

Restriction of editable attributes is via the manager module and the hook:

```bsl
// Модуль менеджера справочника Контрагенты
Функция РеквизитыНеРедактируемыеВГрупповойОбработке() Экспорт
    Результат = Новый Массив;
    Результат.Добавить("ИНН");
    Результат.Добавить("КПП");
    Результат.Добавить("ОсновнойДоговорКонтрагента");
    Возврат Результат;
КонецФункции

// ГрупповоеИзменениеОбъектовПереопределяемый (модуль прикладной конфигурации)
Процедура ПриОпределенииОбъектовСРедактируемымиРеквизитами(Объекты) Экспорт
    Объекты.Вставить(Метаданные.Справочники.Контрагенты.ПолноеИмя(),
        "РеквизитыНеРедактируемыеВГрупповойОбработке");
КонецПроцедуры
```

**Nuances / anti-patterns:**
- ❌ Call `ИзменитьВыделенные` without checking the "Изменение" right - the form
  will open, but saving will fail on the first access error. Check the right in
  the calling code (`ПравоДоступа` or `УправлениеДоступом.ИзменениеРазрешено`
  to account for RLS - see `users-access.md`).
- `РеквизитыНеРедактируемыеВГрупповойОбработке` has **priority** over
  `РеквизитыРедактируемыеВГрупповойОбработке` when both lists are filled.
- Bulk editing works in two modes (controlled in the
  `ГрупповоеИзменениеРеквизитов` form): **controlled** (in a transaction - if
  one object fails, all are rolled back, default mode) and **uncontrolled**
  (outside a transaction, each object is saved independently, the
  `ПрерыватьПоОшибке` flag).
- ❌ Implementing the `ПриОпределенииОбъектовСРедактируемымиРеквизитами` hooks in
  the main `ГрупповоеИзменениеОбъектовКлиент` module is not allowed. The hook
  must be in `ГрупповоеИзменениеОбъектовПереопределяемый` of the **application**
  configuration.

### 6. Subordination structure: the "Related documents" report and hooks

**Task:** the `Related documents` report is generated by БСП by object reference
(navigation panel / command "Reports – Related documents"). The application
configuration affects the output: it overrides object presentation, document
amount/currency, and hides service objects.

The `СтруктураПодчиненности` subsystem does not have a stable programmatic API for
report generation — only **override hooks** in
`СтруктураПодчиненностиПереопределяемый` (БСП calls it, application code
implements it; it is not called directly).

**Hooks:**
`СтруктураПодчиненностиПереопределяемый.ПриОпределенииНастроек(Настройки) Экспорт`
— setting the amount/currency attributes and the set of attributes for object
  presentation in the report.
`СтруктураПодчиненностиПереопределяемый.ПриПолученииПредставления(ТипДанных, Данные, Представление, СтандартнаяОбработка) Экспорт`
— forming the object presentation for output in the report (for objects
  listed in `Настройки.РеквизитыДляПредставления`).
`СтруктураПодчиненностиПереопределяемый.ПередВыводомСвязанногоОбъекта(Объект, СвойстваОбъекта, Отказ) Экспорт`
— allows hiding an object from the report (`Отказ = Истина`) or marking it as
  a service object (`СвойстваОбъекта.ЭтоСлужебный = Истина`).
— all Procedures, region `#Область ПрограммныйИнтерфейс` (override hooks).
  Server.

**Parameters:**
- `Настройки` (Структура):
  - `Реквизиты` (Соответствие) — key: full metadata name of the object;
    value: correspondence of the `Валюта` and `СуммаДокумента` attributes with the actual
    object attributes (if not specified, the `Валюта` and
    `СуммаДокумента` attributes are used).
  - `РеквизитыДляПредставления` (Соответствие) — key: full metadata name;
    value: `Массив` of attribute names for forming the presentation (for these
    objects `ПриПолучениеПредставления` will be called).
- `Объект` (СправочникСсылка / ДокументСсылка / ЗадачаСсылка /
  БизнесПроцессСсылка / ПланВидовХарактеристикСсылка) — the object being output.
- `СвойстваОбъекта` (Структура) — flags: `ЭтоОсновной`, `ЭтоСлужебный`,
  `ЭтоПодчиненный`, `Выводился` (structure `Итого` / `ВПодчиненных`).
- `Отказ` (Булево) — `Истина` → the object is not output (but its subordinate
  objects are output).

**Example:**
```bsl
// СтруктураПодчиненностиПереопределяемый (модуль прикладной конфигурации)
Процедура ПриОпределенииНастроек(Настройки) Экспорт
    // Переопределить реквизиты суммы/валюты для счёта на оплату
    Реквизиты = Новый Соответствие;
    Реквизиты.Вставить("СуммаДокумента",
        Метаданные.Документы.СчетНаОплатуПокупателю.Реквизиты.СуммаОплаты.Имя);
    Реквизиты.Вставить("Валюта",
        Метаданные.Документы.СчетНаОплатуПокупателю.Реквизиты.ВалютаДокумента.Имя);
    Настройки.Реквизиты.Вставить(
        Метаданные.Документы.СчетНаОплатуПокупателю.ПолноеИмя(), Реквизиты);

    // Состав реквизитов для представления исходящего письма
    РеквизитыДляПредставления = Новый Массив;
    РеквизитыДляПредставления.Добавить(
        Метаданные.Документы.ЭлектронноеПисьмоИсходящее.Реквизиты.ДатаОтправления.Имя);
    РеквизитыДляПредставления.Добавить(
        Метаданные.Документы.ЭлектронноеПисьмоИсходящее.Реквизиты.Тема.Имя);
    Настройки.РеквизитыДляПредставления.Вставить(
        Метаданные.Документы.ЭлектронноеПисьмоИсходящее.ПолноеИмя(),
        РеквизитыДляПредставления);
КонецПроцедуры

Процедура ПередВыводомСвязанногоОбъекта(Объект, СвойстваОбъекта, Отказ) Экспорт
    // Скрыть черновики писем из структуры подчинённости
    Если ТипЗнч(Объект) = Тип("ДокументСсылка.ЭлектронноеПисьмоИсходящее")
        И Объект.СтатусПисьма = Перечисления.СтатусыИсходящегоПисьма.Черновик Тогда
        Отказ = Истина;  // не выводить, но подчинённые выведутся
    КонецЕсли;
КонецПроцедуры
```

**Nuances / antipatterns:**
- ❌ Call `СтруктураПодчиненностиПереопределяемый.ПриОпределенииНастроек(…)`
  from application code — this is a hook, and БСП calls it when generating a report.
  Application code only **implements** it in the module with the same name.
- ❌ Look for the module `СтруктураПодчиненности` (without the suffix) — it **does not
  exist**. The subsystem consists entirely of the overridable module and the
  report `Отчет.СвязанныеДокументы`.
- `Отказ = Истина` in `ПередВыводомСвязанногоОбъекта` hides the object itself, but
  **not** its subordinates — they will still be output. To hide the entire subtree,
  use `СвойстваОбъекта.ЭтоСлужебный = Истина` (the object is not required to be
  output, but can be shown if necessary).
- Deprecated hooks `МассивРеквизитовОбъектаДляФормированияПредставления`,
  `ПредставлениеОбъектаДляВыводаВОтчет`, `ИмяРеквизитаДокумента` (region
  `УстаревшиеПроцедурыИФункции`) — do not use in new code; they are replaced by
  `ПриОпределенииНастроек` and `ПриПолучениеПредставления`.

## Additional

Other methods (full signatures — via
`python scripts/bsp_api.py method <Имя> --module <Модуль> --src src/cf`):

- `ПоискИУдалениеДублей.ПроверитьВозможностьЗаменыЭлементовСтрока(ПарыЗамен, ПараметрыЗамены)`
  — ⚠️ `СлужебныйПрограммныйИнтерфейс`: string-based variant of the
  replacement-eligibility check (returns error text, not `Соответствие`).
- `ПоискИУдалениеДублей.ТипыИсключаемыеИзВозможныхДублей()` — ⚠️
  `СлужебныйПрограммныйИнтерфейс`: types excluded from duplicate search by the
  subsystem itself. To extend the set of excluded types, implement the hook
  `ИнтеграцияПодсистемБСП.ПриДобавленииТиповИсключаемыхИзВозможныхДублей`, rather than
  calling this method.
- `ГрупповоеИзменениеОбъектовКлиент.ОбработчикКоманды(Знач МассивСсылок, Знач ПараметрыВыполнения)`
  — ⚠️ `СлужебныйПрограммныйИнтерфейс`: command handler for group changes for
  plug-in commands (called by БСП).
- `ГрупповоеИзменениеОбъектовКлиент.НачатьИзменениеВыделенныхСОповещением(ПараметрыГрупповогоИзменения, ОписаниеОповещения)`
  — ⚠️ `СлужебныйПрограммныйИнтерфейс`: start the change with completion
  notification (used inside the command handler).

Override hooks (modules `*Переопределяемый` — called by БСП, implemented by application
code; not called directly):
- `ПоискИУдалениеДублейПереопределяемый`:
  - `ПриОпределенииОбъектовСПоискомДублей(Объекты)` — which objects participate in
    the search.
  - `ПриОпределенииПараметровПоискаДублей(...)` — application search rules.
  - `ПриПоискеДублей(...)` — post-processing of results.
  - `ПриОпределенииВозможностиЗаменыЭлементов(Знач ИмяОбъектаМетаданных, Знач ПарыЗамен, Знач ПараметрыЗамены, НедопустимыеЗамены)` —
    prevent duplicate replacement by application-specific criteria.
  - `ПриОпределенииОбъектовСКомандамиОбъединенияДублейЗаменыСсылок(Объекты)` —
    in which object forms to show commands for merging duplicates and replacing
    references with the found duplicate.
- `ГрупповоеИзменениеОбъектовПереопределяемый`:
  - `ПриОпределенииОбъектовСКомандойГрупповогоИзмененияОбъектов(Объекты)` — in
    which list forms to show the "Change selected" command.
  - `ПриОпределенииОбъектовСРедактируемымиРеквизитами(Объекты)` — for which
    objects to change the set of available attributes through the manager module
    functions `РеквизитыРедактируемыеВГрупповойОбработке` /
    `РеквизитыНеРедактируемыеВГрупповойОбработке`.
  - `ПриОпределенииРедактируемыхРеквизитовОбъекта(Объект, РедактируемыеРеквизиты, НередактируемыеРеквизиты)`
    — a software restriction for a specific metadata object.

`python scripts/bsp_api.py method <Имя> --src src/cf`.
