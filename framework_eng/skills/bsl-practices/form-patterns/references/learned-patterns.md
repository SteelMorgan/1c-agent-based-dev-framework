# Learned Patterns — form-patterns

Proven techniques and anti-patterns accumulated from real tasks.
`confirmed` — a validated rule, `candidate` — requires revalidation.

```
status: candidate
область: контекстные методы модуля управляемой формы (&НаСервере, &НаКлиенте, без директивы)
приём: Локальные переменные в контекстных методах формы НЕ называть именами зарезервированных
       свойств формы (Параметры, Объект, Элементы, Команды, Модифицированность, ТекущийЭлемент,
       ТекущаяСтрока и т.п.). Имя резолвится в read-only свойство формы, а не в новую локальную.
       Брать иное имя (СтруктураПараметров, ОбъектФормы и т.п.).
антиприём: НЕ писать `Параметры = Новый Структура;` (или присваивание любому зарезервированному
           свойству формы) в контекстном методе формы — падает в рантайме
           "Поле объекта недоступно для записи (<Имя>)". Компиляция/LSP проходят, валидатор молчит:
           ошибка проявляется ТОЛЬКО при выполнении присваивания.
почему: В контекстном методе формы доступны свойства самой формы. "Параметры" — это свойство
        формы (структура параметров открытия, read-only после открытия). Объявление локальной
        с тем же именем трактуется как присваивание свойству → запрет записи.
        В &НаСервереБезКонтекста контекста формы НЕТ → то же имя свободно (обычная локальная).
        Отсюда коварство: идентичный код в без-контекстном методе работает, в контекстном падает —
        легко принять за "разную логику", хотя разница лишь в директиве компиляции.
диагностика: ошибка не видна статикой (LSP/валидатор молчат); ловится рантайм-прогоном —
             модальное окно и стек журнала регистрации укажут точную строку и "(<Имя>)".
источник: headless-форма внешней обработки под БСП, рантайм-прогон, 2026-06
```
