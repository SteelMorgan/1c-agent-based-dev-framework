# План проверки фактов о платформе 1С

## План
1. Создать временную файловую ИБ в /tmp/claude-1000/** (ibcmd/1cv8).
2. Загрузить минимальную конфигурацию с общим модулем + модулем управляемой формы документа, содержащими проверяемый код.
3. Прогнать проверку модулей (CheckModules / ibcmd) — «компилируется/не компилируется» = вердикт для API-фактов.
4. Для поведенческих — минимальный ENTERPRISE-запуск (при необходимости).
5. Зафиксировать сырые доказательства, исправить навыки, sync-skill.py.

## Факты
1. ПланыОбмена.УстановитьНомерОтправленного/Принятого, ОбменДаннымиXML, СоздатьСообщениеОбмена, СоздатьЗаписьСообщения/ЧтениеСообщения
2. ПолучитьФорму() в клиентском коде управляемого приложения
3. Массив.СортироватьПоЗначению() (ожидание: нет)
4. ПредопределённыйЭлемент() vs ПредопределенноеЗначение()
5. ПередЗаписью(Отказ, ПараметрыЗаписи) в модуле УФ + событие ПередЗаписьюНаКлиенте

## Чекпойнты
- (старт) окружение: платформа /opt/1cv8/current, ibcmd/1cv8 присутствуют.

- Конфиг-донор: xml-gen ExchangePlans_ОбменСообщениями. Правки: удалил ConfigDumpInfo.xml (неполный), обнулил Content.xml (ссылался на несуществующие объекты). LoadConfigFromFiles + UpdateDBCfg — успех.
- CheckModules: ЛОВИТ только неизвестные ТИПЫ. ОбменДаннымиXML → "Тип не определен" (ДОКАЗАНО: типа нет). Массив.СортироватьПоЗначению и ПредопределённыйЭлемент компилируются БЕЗ ошибки → метод/функция НЕ проверяются компилятором.
- ВЫВОД МЕТОДИКИ: для методов/глоб.функций нужен RUNTIME (ENTERPRISE + Выполнить + Попытка). Строю харнесс.
