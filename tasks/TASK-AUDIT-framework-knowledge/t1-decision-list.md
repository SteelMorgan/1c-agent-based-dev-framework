# T1: решения по знаниям навыков на основе прогона (2026-07-03)

Источник: `tools/knowledge-probe/results/t1-final/` (56 вопросов T1 × 7 моделей, грейдер GPT-5.5-high).
DeepSeek в основной матрице — @0.7; контрольный прогон @0.3 лежит отдельно:
`results/t1-final/deepseek-t03/grades.jsonl` (вывод: галлюцинации — свойство весов, не сэмплинга).

Правило worst-case: решение о сжатии принимается по самому слабому исполнителю роли,
а не по лучшей модели.

Возможное будущее: пометка `weak-model-critical` — секции, обязательные к подгрузке слабым
исполнителям и опциональные для strong.

## 3. Не знает (почти) никто — незаменимое ядро справочного слоя

Кластеры (18 вопросов, knows+partial ≤ 2 из 7):

- **files-and-versions (Q-BSP-055/057/059)** — точные имена методов РаботаСФайлами,
  поведение при версионировании, регионы ВерсионированиеОбъектов. 6/7 галлюцинируют.
- **esign-mcd (Q-BSP-093/094/096/097)** — модель вызова ЭП (клиент/сервер),
  межмодульные коллизии ПроверитьПодпись/Зашифровать, МЧД ФНС.
- **protection-pd (Q-BSP-102/103/105/106)** — защита персданных целиком:
  поведение методов, общий регистр, deprecated, регистрация событий доступа.
- **commands-external (Q-BSP-034/037)** — коллизия ДобавитьУсловиеВидимостиКоманды,
  где объявлять команды «создать на основании».
- **data-exchange фон (Q-BSP-068)** — регион ВыполнитьОбменДанными*.
- **ДлительныеОперации (Q-BSP-003)** — модуль/метод запуска фоновой функции: галлюцинируют
  даже strong. Ирония: самый используемый паттерн — и самый выдумываемый.
- **YaxUnit (Q-BSL-077)** — структура тестового модуля (ИсполняемыеСценарии).
- **Тонкости УФ (Q-BSL-034)** — семантика контекстных серверных методов формы.

Решение: не сжимать и не удалять ни при каких условиях; это ядро ценности справочников.
Для этих разделов уместно обратное — проверить полноту и точность (частично уже сделано
сегодняшними исправлениями по доказанным галлюцинациям).

## Не попавшие ни в одну группу (~21 вопрос)

Средняя зона: знает 3–5 моделей или широкий разброс partial. Решения отложены до T2/T3.
