# Архив: категории, выведенные из прогона

Решение пользователя (2026-07-02): пробы знаний прогоняются ТОЛЬКО по публичному домену —
BSL (bsl-practices) и BSP (БСП/ssl-patterns). Категории RUL (правила фреймворка), TUL (наш
тулинг) и PRC (наши процессы) — фреймворк-специфика: чистая модель не может знать её по
построению, проба лишь подтверждала бы очевидное. Вопросы сохранены здесь на случай
будущих поведенческих проб (применение знания с меткой/без) — НЕ для прогона знаний из весов.
