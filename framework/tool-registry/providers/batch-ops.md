# Provider: batch-ops

**MCP Server:** [vladimir-kharin/1c-batch](https://github.com/vladimir-kharin/1c-batch)
**Версия:** определяется репозиторием
**Категория:** Утилиты (сборка/разборка конфигурации)
**Транспорт:** определяется реализацией

## Описание

Утилитарный MCP-сервер для пакетных операций с конфигурациями 1С — сборка и разборка (выгрузка) конфигурации. Предоставляет альтернативный механизм работы с файлами конфигурации, дополняющий возможности `test-runner`.

## Предварительные требования

- Платформа 1С:Предприятие (для операций сборки/разборки)
- Настроенная информационная база

---

## Реализуемые Capability

**Прямого маппинга на стандартные capability фреймворка нет.**

Данный провайдер является утилитарным — его tool-ы выполняют пакетные операции, которые частично пересекаются с capability `dump_config` и `build_project` из провайдера `test-runner`, но реализуют их иным способом.

Если основной провайдер `test-runner` недоступен, tool-ы `batch-ops` могут использоваться как альтернатива для:
- Выгрузки конфигурации (аналог `dump_config`)
- Сборки конфигурации (аналог `build_project`)

---

## Доступные tool-ы

| Tool | Описание | Примечание |
|------|----------|------------|
| Сборка конфигурации | Сборка конфигурации из файлов в ИБ | Аналог `build_project` |
| Разборка конфигурации | Выгрузка конфигурации из ИБ в файлы | Аналог `dump_config` |

> Конкретные имена tool-ов и их параметры определяются исходным кодом репозитория.

---

## Когда использовать

1. **Как альтернативу `test-runner`** — если основной провайдер недоступен или не подходит
2. **Для специфических сценариев сборки** — если нужны возможности, не покрываемые `test-runner`
3. **В изолированных средах** — когда доступен только `batch-ops` без EDT/Designer

---

## Ограничения

- Нет прямого маппинга на capability — используется как утилитарный дополнительный провайдер
- Конкретный API зависит от версии репозитория
- Функциональность может пересекаться с `test-runner`
