# Отладочные сообщения (Agent Debug)

> **Триггер:** стандартная диагностика (журнал регистрации, скриншоты) не позволила установить фактическое поведение системы. При срабатывании — применить навык `agent-debug` (`framework/skills/tool-usage/diagnostics/agent-debug/SKILL.md`).

**ВАЖНО:** это критичный триггер. Не пропускай его при «невидимых» ошибках — вставка временных точек логирования часто единственный способ понять реальный путь выполнения.
