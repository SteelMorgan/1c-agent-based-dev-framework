# RLM Workflow

> **Триггер:** одно из событий ниже. При срабатывании — применить навык `rlm-workflow` (`framework/skills/framework-meta/rlm-workflow/SKILL.md`) и выполнить соответствующий ритуал.

| Событие (триггер) | Ритуал в навыке |
|---|---|
| Пользователь начал сессию словом **«контекст»** / **«context»** | «контекст» |
| Пользователь сказал **«суммаризируем»** / **«summarize»** | «суммаризируем» |
| Пользователь сказал **«новая задача»** / **«new task»** | «новая задача» |
| CRIT-инжект из `context-monitor.sh` (`≥80%` или `≥300k tokens`) | «суммаризируем» |
| Срабатывание `pre-compact.sh` перед компактом | «суммаризируем» (короткий вид: шаги 1, 3, 4) |
| Узнал устойчивый паттерн / принял архитектурное решение по ходу работы | «запись по ходу работы» |

## MUST (инвариант, всегда)

- Ритуал «суммаризируем» обязан завершаться РОВНО строкой `Контекст сохранён в RLM. Жми /clear.` — без неё пользователь не поймёт, безопасно ли `/clear`.
- PENDING-факт обязателен и пишется с префиксом `PENDING tasks next session:` — без префикса ритуал «контекст» его не найдёт.
- Любая запись в RLM — только после `rlm_start_session` (иначе молчаливый провал).

Пошаговые процедуры ритуалов, уровни H-MEM, форматы и анти-паттерны — в навыке `rlm-workflow`.
