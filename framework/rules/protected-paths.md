# Protected Paths Policy

Глобальное правило безопасности. Приоритет над любыми действиями агентов.

## Защищённые пути (deny-by-default)

- `**/exts/YAXUNIT/**`

Любое совпадение = запрет на создание/изменение/удаление.

## Поведение при блокировке

Если исправление требует protected path:

1. НЕ вносить изменения в protected path
2. Зафиксировать статусы: `test_failure` + `suspected_test_error` + `blocked_by_protected_path`
3. Указать обоснование и path(s) под запретом
4. Остановиться и передать задачу оркестратору/пользователю

**developer-code:** исправляет только ошибки в собственном коде текущей сессии; все остальные случаи (ошибка теста, инфраструктуры, protected path) — блокировка по протоколу выше.
