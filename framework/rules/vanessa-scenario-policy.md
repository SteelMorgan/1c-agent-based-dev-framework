# Политика сценариев Vanessa Automation

## MUST

- **Не гадай — смотри в код.** Не предполагай логику проверок, обработчиков и событий формы — читай модуль формы, модуль объекта, модуль менеджера. Изучение кода предпочтительно делегировать сабагенту (Explorer или `code-navigation`) — это экономит контекст и даёт структурированный результат. Если поведение кода не соответствует ожиданиям теста — это не ошибка теста, а найденное несоответствие: зафиксируй как результат
- Сценарий опирается на спецификацию задачи или существующий бизнес-кейс — без вымышленных кейсов
- Один сценарий = одно наблюдаемое поведение
- Перед новым шагом — искать существующий в библиотеке Vanessa и сценариях проекта
- Первый сценарий для нового кейса — короткий smoke
- Сценарий выполняется под конкретным бизнес-пользователем, а не под admin/AgentAI — исключение только если проверяемая функция доступна исключительно администратору; пользователь определяется из описания задачи, при отсутствии — **спросить у человека**

## MUST (продолжение)

- **Тег задачи обязателен.** Каждый `.feature`-файл MUST содержать тег `@task-<ID>` (например `@task-103`), где `<ID>` — идентификатор задачи из трекера. Если задача пришла без ID — использовать краткий slug (`@task-оформление-заказа-20260325`). Тег ставится на уровне `Функциональность:` — так все сценарии файла наследуют привязку.
- **Комментарий-источник.** В шапке файла (перед тегами) MUST быть комментарий: `# Задача: <ID> — <название>`. Это человекочитаемая ссылка для быстрой навигации.

## SHOULD

- Подготовка данных вынесена из основного сценария
- Подготовка данных вынесена из основного сценария
- Ожидание через состояние UI, не через внутренние детали

## Источник сценария

- Новая задача: по утверждённой спецификации (до или параллельно реализации)
- Реализованная задача: по реальному кейсу (закрепление регрессии)

## Антипаттерны

| Антипаттерн | Последствие |
|-------------|-------------|
| Выдуманный поток без проектного источника | Не защищает реальное требование |
| Длинный сценарий на 5-7 смыслов | Нестабилен, сложно диагностируется |
| Проверка внутренних деталей вместо поведения | Хрупкий сценарий |
