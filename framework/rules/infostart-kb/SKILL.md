# База знаний Infostart (перед разработкой 1С)

> **Триггер:** перед написанием, отладкой или проектированием кода 1С:Предприятие (документы, регистры, БСП, управляемые формы, расширения, запросы, обмен и т.д.). При срабатывании — применить навык `infostart-kb` (`framework/skills/other/infostart-kb/SKILL.md`).

База содержит сотни тысяч реальных решений и известных ошибок сообщества — её использование для задач по 1С обязательно.
