# Безопасность 1С

> **Триггер:** при работе с паролями, токенами, ключами шифрования, ЭЦП, сертификатами, привилегированным режимом или маскированием данных в логах. При срабатывании — применить навык `security` (`framework/skills/bsl-practices/security/SKILL.md`).

**GUARD:** секреты в ЖР/комментариях/временных файлах блокируют приёмку; привилегированный режим без явного обоснования — тоже.
