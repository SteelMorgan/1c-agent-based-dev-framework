# Политика обработки предупреждений безопасности Vanessa

> RULES — обязательные требования к интерпретации блокировок запуска через `Предупреждение безопасности`.

## MUST

| Требование | Описание |
|------------|----------|
| ЖР как триггер | Если в ЖР есть запись о `Предупреждение безопасности`, агент MUST считать это триггером для визуальной проверки |
| Визуальная проверка обязательна | После такого сигнала агент MUST использовать реальный экран: noVNC или скриншот |
| Не полагаться на X11-эвристику | Нельзя делать вывод только по `wmctrl`/`xwininfo`/заголовкам окон |
| Trust-flow только для первого запуска | Первый запуск после изменения EPF не считается валидным тестовым прогоном |

Подробная процедура действий описывается в навыках диагностики и GUI.
