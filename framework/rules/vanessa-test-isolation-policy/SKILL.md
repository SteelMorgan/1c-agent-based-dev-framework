# Политика изоляции тестовых данных Vanessa

> **Триггер:** написание сценария, который создаёт, изменяет или записывает объекты в БД. При срабатывании — применить навык `vanessa-authoring` (`framework/skills/tool-usage/vanessa/vanessa-authoring/SKILL.md`).

## Критерий изоляции (MUST)

| Тест записывает в СУБД? | Изоляция | Данные |
|---|---|---|
| Да | **Полная** | Тест создаёт свои объекты |
| Нет | Ослабленная | Существующие стабильные объекты |

Главный вопрос: **сможет ли тест пройти повторно** без вмешательства? Если нет — повысить изоляцию.

## MUST при полной изоляции

- Тест создаёт собственный документ/объект в начале сценария.
- Идентификаторы передаются между шагами через переменные Vanessa (`$VarName$`).
- При переключении TestClient — документ записан и закрыт **до** переключения.
- Не проводить тестовые документы без необходимости — движения влияют на другие тесты.
- Бизнес-критичные зависимости (контрагенты с договорами, настройки лимитов) фиксировать в комментарии сценария с указанием конкретного объекта.
