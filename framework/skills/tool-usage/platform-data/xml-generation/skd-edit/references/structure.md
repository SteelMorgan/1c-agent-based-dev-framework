# Структура варианта

Операция: `modify-structure`.

Для **создания** структуры с нуля используй `set-structure` из skd-dsl (compile). Эта Skill охватывает только точечную модификацию полей группировки уже существующей именованной группы.

## modify-structure — изменить поля группировки существующей группы

Shorthand: `"Поле1, Поле2, ... @name=ИмяГруппы"`.

```
"Валюта @name=ДанныеОтчета"
"Валюта, НаименованиеБанка @name=ДанныеОтчета"
"details @name=ДанныеОтчета"
"Организация > Номенклатура @name=Основная"
```

### Семантика

- Находит группировку по `<dcsset:name>ИмяГруппы</dcsset:name>`.
- **Заменяет только `<groupItems>`** — список полей, по которым идёт группировка.
- **Сохраняет** в неизменном виде:
  - `<selection>` — элементы выборки группы;
  - `<order>` — сортировку группы;
  - `<filter>` — отбор группы;
  - `<conditionalAppearance>` — условное оформление группы;
  - `<outputParameters>` — параметры вывода группы.
- `@name=` **обязателен**. Без явного имени группы операция падает с ошибкой — неоднозначно, какую группу патчить.

### Синтаксис groupItems

| Форма | Семантика |
|-------|-----------|
| `Поле1, Поле2` | Несколько полей в одной группировке (одна группа группирует по нескольким измерениям). |
| `Поле1 > Поле2` | Вложенный уровень — `>` создаёт sub-группу. |
| `details` | Детальные записи (вместо полей группировки). |

> **Замечание.** Запись `Поле1 > Поле2 @name=X` модифицирует группу `X` и заменяет её `groupItems` цепочкой вложенных группировок. Это сильное изменение — обычно `modify-structure` применяют к одной плоской группе.

### Когда использовать

- Поменять измерение, по которому строится отчёт, без потери настроек оформления, фильтров и выборки.
- Перевести группу в режим `details` или наоборот.

### Когда НЕ использовать

- Перестроить всё дерево структуры целиком → `set-structure` из skd-dsl (полная замена с потерей всех настроек групп).
- Дать группе имя, если у неё его не было → структура должна быть пересобрана через `set-structure ... @name=...`.

## Edge cases

| Случай | Поведение |
|--------|-----------|
| `@name=` не указан | Error: «name is required for modify-structure». |
| Группы с указанным именем нет | Error: «group not found». |
| Два варианта с одной и той же группой имени | Берётся `--variant` (по умолчанию первый). Используй явный `--variant <name>`. |
| Группа имела `details`, новое значение — `Поле1` | `groupItems` заменяются: details → одно измерение. Selection/CA сохраняются. |
| Группа имела `Поле1`, новое значение — `details` | Аналогично: groupItems превращаются в детальные записи. |
| Поле в `groupItems` отсутствует в `dataSet` | Запишется как есть; ошибка проявится при `validate --level semantic`. |

## Не входит в этот skill

| Задача | Решение |
|--------|---------|
| Создать структуру с нуля | `set-structure` в skd-dsl. |
| Полностью переписать структуру варианта | `set-structure` в skd-dsl. |
| Изменить Selection/CA/order одной группы | Сейчас — пересобрать вариант через skd-dsl. Точечных операций над содержимым группы (кроме `groupItems`) в этом skill нет. |
