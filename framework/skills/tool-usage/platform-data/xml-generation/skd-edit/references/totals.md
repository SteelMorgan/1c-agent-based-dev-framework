# Итоги (totals)

Операции: `add-total`, `remove-total`.

## add-total — добавить итог

Shorthand: `"<dataPath>: <выражение>"`.

```
"Цена: Среднее"                  # → Среднее(Цена)
"Количество: Сумма"              # → Сумма(Количество)
"Стоимость: Сумма(Кол * Цена)"   # как есть (явная функция со скобками)
"Маржа: Маржа"                   # identity: <выражение>=Маржа (для вычисляемого поля)
"Проверка: ЕстьNULL(СуммаОстаток, 0)"  # произвольное выражение
```

### Автообёртка аггрегатных функций

Если выражение — **известная функция без скобок** — оно автоматически оборачивается в `Func(dataPath)`:

| Функция | Семантика |
|---------|-----------|
| `Сумма` | `Сумма(<dataPath>)` |
| `Среднее` | `Среднее(<dataPath>)` |
| `Количество` | `Количество(<dataPath>)` |
| `Минимум` | `Минимум(<dataPath>)` |
| `Максимум` | `Максимум(<dataPath>)` |

### Не-агрегатные функции и identity

Если выражение **со скобками** — используется как есть (`Сумма(Кол * Цена)`, `ЕстьNULL(СуммаОстаток, 0)`).

Если выражение **без скобок и не из списка агрегатов** — используется как есть (identity-кейс: `Маржа: Маржа` → `<expression>Маржа</expression>`). Это позволяет включать в итоги вычисляемые поля и константы.

Не-агрегатные функции (`ЕстьNULL`, `ВЫРАЗИТЬ`, `ВЫБОР КОГДА...`) пиши со скобками, чтобы парсер не пытался обернуть.

### Поведение

- Поддерживает batch через `;;`.
- Дубликат `<dataPath>` в `<totalFields>` — warning + skip. Чтобы переопределить выражение — сначала `remove-total`, затем `add-total`.
- Поле, на которое ставится итог, **должно существовать** в наборе (как `field` или `calculatedField`). Иначе СКД не скомпонуется — `xml-gen validate --type skd --level semantic` поймает.

## remove-total — удалить итог

Value — `dataPath`.

```
"Цена"
"Цена ;; Количество ;; Сумма"
```

Удаляет запись из `<totalFields>`. Отсутствующий итог — warning + skip (идемпотентно).

## Edge cases

| Случай | Поведение |
|--------|-----------|
| `add-total "X: Сумма"` для несуществующего поля X | Скрипт добавит запись; ошибка проявится при `validate --level semantic`. |
| `add-total "X: SUM"` (англоязычная функция) | Identity — выражение `<expression>SUM</expression>`, что некорректно. Используй русские имена. |
| `add-total "X: Сумма(X)"` | Эквивалентно `add-total "X: Сумма"` — обе формы дают `Сумма(X)`. |
| `add-total "X: Среднее(Y)"` для разных полей | Допустимо — `dataPath=X`, `expression=Среднее(Y)`. |
| Итог по вычисляемому полю | Работает, если поле — `calculatedField` и присутствует в наборе. |
