# MXL DSL — полная спецификация

Канонический формат описания табличного документа 1С. Используется `xml-gen mxl compile/decompile`.

## Верхний уровень

| Поле | Обяз. | По умолч. | Описание |
|------|:-----:|-----------|----------|
| `columns` | да | — | Количество колонок макета |
| `page` | нет | — | Формат страницы. Значения: `"A4-landscape"` (780), `"A4-portrait"` (540) или число. Если задан и все колонки используют `"Nx"`, **автоматически вычисляет `defaultWidth`** из суммы пропорций так, чтобы суммарная ширина уложилась в `page` |
| `defaultWidth` | нет | `10` | Ширина колонок по умолчанию. Игнорируется, если задан `page` и все ширины — `"Nx"` |
| `columnWidths` | нет | `{}` | Карта ширин колонок. Подробнее ниже. |
| `fonts` | нет | — | Именованные шрифты. Если не задан, создаётся `default` (Arial 10) |
| `styles` | нет | `{}` | Именованные стили |
| `areas` | да | — | Массив именованных областей в порядке вывода |

### `columnWidths` — ключи и значения

**Ключи** (1-based):
- одиночный индекс: `"1"`, `"5"`
- диапазон: `"2-8"` — колонки 2..8 включительно
- список через запятую: `"5,7,9"` — указанные колонки
- комбинации: `"2-8,12"` допустимы

**Значения**:
- число — абсолютная ширина в условных единицах 1С
- строка `"Nx"` — множитель относительно `defaultWidth` (например `"2x"`, `"0.5x"`, `"1.5x"`). Используется в паре с `page` для пропорционального масштабирования

Пример:

```json
"columnWidths": {
  "1":     5,        // абсолютная ширина первой колонки
  "2-8":   "1x",     // 7 колонок по defaultWidth
  "9-10":  "2x",     // 2 колонки удвоенной ширины
  "11,13": 30        // нечётные конкретные колонки
}
```

## Шрифты — `fonts.<name>`

| Поле | По умолч. | Описание |
|------|-----------|----------|
| `face` | `"Arial"` | Имя шрифта |
| `size` | `10` | Размер кегля |
| `bold` | `false` | Жирный |
| `italic` | `false` | Курсив |
| `underline` | `false` | Подчёркнутый |
| `strikeout` | `false` | Зачёркнутый |

Шрифт с именем `"default"` используется, если стиль не задал `font` явно. При отсутствии в DSL создаётся автоматически (Arial 10).

## Стили — `styles.<name>`

| Поле | По умолч. | Описание |
|------|-----------|----------|
| `font` | `"default"` | Ссылка на имя шрифта из `fonts` |
| `align` | — | Горизонтальное выравнивание: `left`, `center`, `right` |
| `valign` | — | Вертикальное выравнивание: `top`, `center`, `bottom` |
| `border` | — | Стороны рамки. Значения: `all`, `none`, `top`, `bottom`, `left`, `right`. Через запятую: `"top,bottom"`, `"left,right,bottom"` |
| `borderWidth` | `"thin"` | Толщина рамки: `thin` (1px) или `thick` (2px). Задаётся **на уровне стиля**, не на ячейке |
| `wrap` | `false` | Перенос длинного текста по словам |
| `format` | — | Формат данных 1С. Примеры: `"ЧЦ=15; ЧДЦ=2"`, `"ДФ=dd.MM.yyyy"`, `"ЧРГ=,"`, `"Л=ru_RU"` |

## Области — `areas[]`

| Поле | Обяз. | Описание |
|------|:-----:|----------|
| `name` | да | Имя области (используется `Макет.ПолучитьОбласть("Имя")`) |
| `rows` | да | Массив строк |

Порядок областей в массиве = порядок строк в результирующем XML. Decompile сохраняет порядок по позиции в документе (не по алфавиту).

## Строки — `rows[]`

| Поле | По умолч. | Описание |
|------|-----------|----------|
| `height` | — | Высота строки. Если не задана — авто |
| `rowStyle` | — | Имя стиля, который применяется ко **всем** колонкам строки (см. ниже) |
| `cells` | `[]` | Массив явных ячеек |
| `empty` | — | Количество подряд идущих **пустых строк**. `{ "empty": 3 }` ≡ `{}, {}, {}` |

Строка без `cells` и `rowStyle` — пустая.

## Ячейки — `cells[]`

| Поле | Обяз. | По умолч. | Описание |
|------|:-----:|-----------|----------|
| `col` | да | — | Позиция колонки (1-based) |
| `span` | нет | `1` | Объединение по горизонтали (число колонок) |
| `rowspan` | нет | `1` | Объединение по вертикали (число строк) |
| `style` | нет | `rowStyle` строки | Имя стиля. Переопределяет `rowStyle` |
| `text` | нет | — | Статический текст (fillType=Text) |
| `param` | нет | — | Имя параметра заполнения (fillType=Parameter) |
| `template` | нет | — | Шаблонный текст с подстановками `[Параметр]` (fillType=Template) |
| `detail` | нет | — | Параметр расшифровки. Использовать **вместе** с `param`. При клике откроет объект, указанный в этом параметре |

### Автоопределение `fillType`

Компилятор выбирает тип заполнения ячейки по наличию ключей:

| Ключ в ячейке | fillType |
|---------------|----------|
| `param` | `Parameter` |
| `template` | `Template` |
| `text` | `Text` |
| ничего (только `style`/`col`/`span`) | без fillType — пустая ячейка/рамка |

**Не смешивать**: одна ячейка — один тип заполнения. Если нужен текст и параметр в одной ячейке (`"Инв № [Номер]"`) — это `template`, а не `text + param`.

### `detail` — расшифровка

```json
{ "col": 2, "span": 6, "param": "Товар", "detail": "Номенклатура" }
```

Ячейка показывает `Товар`, но при двойном клике в режиме просмотра пользователь провалится в объект `Номенклатура`. В BSL заполняются **оба** параметра:

```bsl
Область.Параметры.Товар        = Строка.НоменклатураПредставление;
Область.Параметры.Номенклатура = Строка.Номенклатура; // ссылка для расшифровки
```

## `rowStyle` — автозаполнение строки

Когда у строки задан `rowStyle`, компилятор:

1. Создаёт явные ячейки во всех колонках от 1 до `columns`.
2. Колонки, для которых **есть явная ячейка** в `cells` — применяют свой `style` (или наследуют `rowStyle`, если `style` не задан).
3. Колонки без явной ячейки получают пустую ячейку со стилем `rowStyle` — это даёт сплошные рамки.
4. Если в **предыдущих строках** той же области есть ячейки с `rowspan > 1`, занятые ими колонки пропускаются (не перекрываются заполнением).

Используется для:
- табличных строк со сплошной рамкой (только некоторые колонки имеют данные)
- шапок таблиц
- итоговых строк с верхней линией

## `rowspan` — вертикальное объединение

```json
[
  { "rowStyle": "bordered", "cells": [
    { "col": 1, "rowspan": 3, "param": "НомерЛота" },
    { "col": 2, "text": "Стр1" }
  ]},
  { "rowStyle": "bordered", "cells": [
    { "col": 2, "text": "Стр2" }
  ]},
  { "rowStyle": "bordered", "cells": [
    { "col": 2, "text": "Стр3" }
  ]}
]
```

В строках 2-3 колонка 1 уже занята rowspan — `rowStyle` пропустит её при автозаполнении.

## Форматы 1С (поле `format`)

Самые частые:

| Формат | Назначение |
|--------|------------|
| `"ЧДЦ=2"` | Числа: 2 знака после запятой |
| `"ЧЦ=15; ЧДЦ=2"` | Числа: всего 15 цифр, 2 после запятой |
| `"ЧРГ=,"` | Разделитель групп разрядов — запятая |
| `"ДФ=dd.MM.yyyy"` | Дата: ДД.ММ.ГГГГ |
| `"ДФ=dd.MM.yyyy HH:mm"` | Дата+время |
| `"Л=ru_RU"` | Локаль |

Несколько токенов разделяются `;`.

## Ограничения текущей версии

Спецификация **не** покрывает:
- Множественные наборы колонок (`columnsID`) для пересечений Rows×Columns — для **создания**. Чтение через `mxl info` поддерживается.
- Drawing-области (рисунки/штрихкоды/картинки) — компиляция не реализована, info — да.
- Фон ячеек (`BackColor`).

Если нужны эти возможности — собрать макет в конфигураторе, декомпилировать, доработать.
