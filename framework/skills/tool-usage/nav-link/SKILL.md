# Работа с навигационными ссылками (Nav Link)

## Назначение

Навык учит агента **работать с навигационными ссылками** формата `e1cib/data/...` — разбирать ссылку на тип объекта и ссылку, формировать ссылку по данным. Используется когда пользователь передаёт ссылку на объект (контрагент, документ) и просит найти связанные данные.

**Принцип:** Ссылка e1cib/data/... → `parse_nav_link` → тип + ссылка → запросы/анализ. Результаты запроса → `get_nav_link` → ссылка для ответа пользователю.

---

## Когда применять

| Триггер | Действие |
|---------|----------|
| Пользователь даёт ссылку e1cib/data/... | `parse_nav_link` — извлечь тип объекта и ссылку |
| Нужно сформировать ссылку по данным из запроса | `get_nav_link` — тип объекта + ссылка |
| Задача «покажи данные по этому контрагенту/документу» | parse_nav_link → execute_query с параметром по ссылке |

---

## Сценарии использования

### Сценарий 1: Разбор ссылки от пользователя

**Шаги:**

1. Пользователь: «Покажи задолженность по контрагенту: e1cib/data/Справочник.Контрагенты?ref=...»
2. `parse_nav_link` — извлечь тип (Справочник.Контрагенты) и ref.
3. Построить запрос с параметром по ссылке.
4. `execute_query` — получить данные.

### Сценарий 2: Формирование ссылки в ответе

**Шаги:**

1. `execute_query` вернул строку с полем-ссылкой.
2. `get_nav_link` — сформировать навигационную ссылку по типу объекта и значению ссылки.
3. Вернуть пользователю ссылку в удобном формате.
