# Замена MCP-инструментов (Tool Replacement)

> **Назначение:** Этот навык учит агента **заменять MCP-инструменты** (capabilities) в навыках фреймворка при смене MCP-сервера или инструмента на аналог.

---

## Когда использовать

Используй этот навык, когда:
- Пользователь хочет заменить MCP-сервер на другой (например, `bsl-language-server` на альтернативный LSP)
- Нужно адаптировать навыки под другой набор инструментов с похожей функциональностью
- Требуется мигрировать с одного MCP-провайдера на другой

---

## Принцип замены инструментов

### 1. Идентификация зависимостей

**Шаг 1:** Найди все навыки, использующие заменяемый инструмент.

```bash
# Поиск упоминаний capability в навыках
grep -r "search_syntax_reference" framework/skills/
grep -r "check_syntax" framework/skills/
```

**Шаг 2:** Составь список затронутых навыков:
- Навыки в `tool-usage/` — напрямую описывают работу с инструментом
- Навыки в `bsl-practices/` — могут ссылаться на capability в примерах
- Правила в `rules/` — могут требовать использование capability

### 2. Маппинг старого инструмента на новый

Создай таблицу соответствия:

| Старый инструмент | Новый инструмент | Изменения в параметрах |
|-------------------|------------------|------------------------|
| `search_syntax_reference(query)` | `lsp_search(symbol, type="syntax")` | Параметр `query` → `symbol` |
| `check_syntax(file)` | `validate_bsl(path)` | Параметр `file` → `path` |
| `get_type_info(type)` | `lsp_hover(symbol)` | Возвращает другую структуру |

### 3. Обновление навыков

Для каждого затронутого навыка:

**A. Навыки `tool-usage/`**

Эти навыки **полностью описывают** работу с инструментом. Требуется:
1. Обновить название capability
2. Обновить параметры вызова
3. Обновить примеры использования
4. Обновить описание возвращаемых данных

**Пример (было):**
```markdown
## Capability: search_syntax_reference

**Параметры:**
- `query` (string) — поисковый запрос

**Пример:**
```python
result = search_syntax_reference("СправочникМенеджер.Номенклатура")
```

**Пример (стало):**
```markdown
## Capability: lsp_search

**Параметры:**
- `symbol` (string) — имя символа
- `type` (string) — тип поиска: "syntax", "definition", "references"

**Пример:**
```python
result = lsp_search(symbol="СправочникМенеджер.Номенклатура", type="syntax")
```

**B. Навыки `bsl-practices/`**

Эти навыки **ссылаются** на capability в контексте. Требуется:
1. Найти упоминания старого инструмента
2. Заменить на новый с корректными параметрами
3. Проверить, что контекст остался понятным

**Пример (было):**
```markdown
Перед использованием метода `НачатьТранзакцию()` проверь его существование через `search_syntax_reference("НачатьТранзакцию")`.
```

**Пример (стало):**
```markdown
Перед использованием метода `НачатьТранзакцию()` проверь его существование через `lsp_search(symbol="НачатьТранзакцию", type="syntax")`.
```

**C. Правила `rules/`**

Правила **требуют** использование capability. Требуется:
1. Обновить название capability в требованиях
2. Обновить escape hatch (если capability недоступна)

**Пример (было):**
```markdown
| Первое использование встроенного типа/метода | `search_syntax_reference` | Вызвать ДО написания кода |
```

**Пример (стало):**
```markdown
| Первое использование встроенного типа/метода | `lsp_search` | Вызвать ДО написания кода |
```

### 4. Обновление зависимостей

Если заменяемый инструмент был частью MCP-сервера, указанного в зависимостях:

**Было:**
```yaml
# В конфигурации проекта
mcp_servers:
  - bsl-language-server
```

**Стало:**
```yaml
mcp_servers:
  - alternative-bsl-lsp
```

- [ ] Найдены все навыки, использующие старый инструмент
- [ ] Создана таблица маппинга старый → новый
- [ ] Обновлены навыки `tool-usage/` (полное описание capability)
- [ ] Обновлены навыки `bsl-practices/` (упоминания в контексте)
- [ ] Обновлены правила `rules/` (требования к использованию)

## Типичные ошибки

### ❌ Забыть обновить примеры в навыках

**Проблема:** Навык описывает новый инструмент, но примеры используют старый.

**Решение:** Grep по всем примерам кода в навыке:
```bash
grep -A 5 '```python' framework/skills/tool-usage/syntax-checking/SKILL.md
```

### ❌ Не обновить escape hatch в правилах

**Проблема:** Правило требует старый инструмент, но он больше не доступен.

**Решение:** Обновить название capability в разделе "Escape hatch":
```markdown
Если capability **lsp_search** недоступна, агент MUST зафиксировать факт и продолжить без проверки.
```

### ❌ Не проверить изменения в структуре ответа

**Проблема:** Новый инструмент возвращает данные в другом формате.

**Решение:** Обновить описание возвращаемых данных в навыке `tool-usage/`:
```markdown
**Возвращает:**
```json
{
  "symbol": "НачатьТранзакцию",
  "type": "function",
  "signature": "НачатьТранзакцию()",
  "documentation": "..."
}
```
