# Навык: Quick Fix (short-цикл)

> Три шага без кросс-ревью. Один файл, < 20 строк, без архитектурных решений, без новых фич,
> без новых объектов метаданных.

## Когда применяется

Lead (главный поток) классифицировал задачу как **простую** (см. профиль оркестратора, Слой 1) и
выбрал short-цикл. В short-цикле Lead вправе исполнить сам или делегировать одного сабагента — под
guard ниже.

## Guard на self-путь (MUST, иначе скользкий склон)

> self-исполнение — единственный режим, где у главного потока нет кросс-ревью. Поэтому границы жёсткие
> и проверяются ДО начала правки.

- self разрешён ТОЛЬКО в границах: `< 20 строк, 1 файл, без новых объектов метаданных, без
  архитектурных решений`;
- **превышение любого критерия → принудительный переход в full-цикл (делегирование), self запрещён**;
- **verify-шаг (шаг 3) обязателен ДАЖЕ для self** — единственная компенсация отсутствия кросс-ревью.

## Шаги

### 1. Найти (Explorer → Economy)

`navigate_symbol` + `get_call_graph` → путь к модулю, зависимости, убедиться что изменение локализовано
(подтверждение границ guard: один файл, нет архитектурных связей).

### 2. Исправить (Developer → Mid)

Минимально необходимое изменение по `coding-standards`. Без «улучшений» за рамками задачи.

### 3. Проверить (Developer → Mid) — ОБЯЗАТЕЛЬНО, в т.ч. для self

1. `get_diagnostics` — быстрая проверка изменённого файла
2. `run_tests` — если есть тесты для модуля
3. `check_syntax` — финальная проверка перед коммитом

## Эскалация на full-цикл

| Ситуация | Действие |
|----------|----------|
| Тесты падают после изменения | Исправить или эскалировать в full |
| Несколько модулей / архитектура / ревью / > 20 строк / новый объект метаданных | full-цикл |

**Протокол эскалации:** зафиксировать состояние → **оркестратор у себя же поднимает фазовый манинг**.
Дисциплина оркестрации и форма фаз уже durable в его профиле (`framework/subagents/orchestrator.md`,
Слой 2); детальную фазовую механику он читает из `framework/workflows/full-cycle.md` по входу в фазу.
Это НЕ «передача во внешний документ» и НЕ запуск другой сессии — Lead просто надевает шляпу
оркестратора full-цикла и идёт с Phase 1 (или Phase 3, если спека уже есть).
