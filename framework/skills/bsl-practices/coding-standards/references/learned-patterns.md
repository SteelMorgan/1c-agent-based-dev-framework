# Learned Patterns — coding-standards

Проверенные приёмы и антиприёмы, накопленные из реальных задач.
`confirmed` — подтверждённое правило, `candidate` — требует повторного подтверждения.

---

```
status: candidate
область: имена формальных параметров процедур/функций BSL
антиприём: НЕ называть формальный параметр процедуры/функции зарезервированным словом
           языка BSL (например Знач — это ключевое слово передачи по значению). Такое
           имя параметра даёт ошибку компиляции «Ожидается имя формального параметра»
           при реальной сборке/загрузке модуля.
приём: перед фиксацией имени параметра проверять его на коллизию с зарезервированными
       словами языка BSL; коллизию обнаруживать не по «LSP молчит», а по факту реальной
       сборки/прогона модуля — LSP-чистота НЕ является доказательством компилируемости.
почему: BSL LSP-мост не покрывает эту категорию синтаксических ошибок — module_health/
        document_diagnostics могут показывать 0 диагностик на модуле, который платформа
        реально не компилирует. Ложно-чистый статус LSP создаёт уверенность в
        работоспособности кода, не подтверждённую сборкой.
источник: TASK-209 GBIG PAM (2026-07-20), developer-tests: параметр с именем `Знач`
          давал «Ожидается имя формального параметра» при сборке, при этом BSL LSP
          показывал 0 диагностик на модуле.
```
