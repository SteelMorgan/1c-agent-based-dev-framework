# Печатные формы на MXL-макетах

## Назначение

Используй этот навык для печатных форм, где результат строится как `ТабличныйДокумент` из MXL-областей.

Оформление макета проектируй через `mxl-layout-patterns`. Этот навык описывает прикладной слой печатной формы:

- где взять данные;
- как получить макет;
- как заполнить параметры;
- в каком порядке вывести области;
- как вернуть результат в механизм печати.

## Отличие от СКД на своем макете

Печатная форма сама управляет заполнением и порядком вывода:

```bsl
Макет = ПолучитьМакет("Макет");
Область = Макет.ПолучитьОбласть("Строка");
Область.Параметры.Поле = Значение;
ТабличныйДокумент.Вывести(Область);
```

СКД на своем макете заполняет параметры через выражения СКД и `groupTemplate`. Для этого используй `skd-custom-layout`.

## Workflow

1. Определи назначение печатной формы и команду печати.
2. Подготовь данные без прямого доступа к СУБД.
3. Спроектируй MXL-макет через `mxl-layout-patterns`.
4. Определи области:
   - заголовок;
   - шапка;
   - строка;
   - группа;
   - итог;
   - подвал.
5. Определи параметры каждой области.
6. Напиши код заполнения параметров и вывода областей.
7. Интегрируй результат в штатный механизм печати.
8. Проверь runtime-формирование и визуальный результат.

Если визуальный каркас пришел из imported Excel/MXL, не считай задачу решенной самим фактом импорта.
Печатная форма начинается там, где код явно берет ответственность за:

- заголовки и служебные подписи;
- привязку данных к параметрам или координатам;
- итоги и пересчеты;
- порядок вывода и скрытие редакторской сетки, если нужен печатный вид.

## Минимальный шаблон

```bsl
ТабличныйДокумент = Новый ТабличныйДокумент;
Макет = ПолучитьМакет("Макет");

ОбластьШапка = Макет.ПолучитьОбласть("Шапка");
ЗаполнитьЗначенияСвойств(ОбластьШапка.Параметры, ДанныеШапки);
ТабличныйДокумент.Вывести(ОбластьШапка);

ОбластьСтрока = Макет.ПолучитьОбласть("Строка");
Для Каждого СтрокаДанных Из ТаблицаДанных Цикл
    ЗаполнитьЗначенияСвойств(ОбластьСтрока.Параметры, СтрокаДанных);
    ТабличныйДокумент.Вывести(ОбластьСтрока);
КонецЦикла;

Возврат ТабличныйДокумент;
```

Используй штатные паттерны конфигурации и БСП-паттерны получения макета и регистрации печатной формы, если конфигурация работает через подсистему печати.

## Что проверять

- Макет найден штатным способом.
- Все области существуют.
- Все параметры заполняются.
- Табличный документ формируется без ошибок.
- Количество строк соответствует данным.
- Пустые значения обрабатываются явно.
- Runtime-результат сохранен или снят для проверки.
- Визуальная проверка проходит через `mxl-layout-patterns`: layout, border, style и negative checks.
- Если макет пришел из Excel-импорта, отдельно зафиксировано, что перенес импорт, а что достроено
  кодом печатной формы.

## Связанные навыки

- `mxl-layout-patterns` — визуальная модель макета.
- `ssl-patterns` — если используется БСП-механизм печати.
- `query-patterns` — если для данных нужна новая 1C-запросная логика.
