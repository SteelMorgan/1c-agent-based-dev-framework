# SKD DSL

JSON DSL для генерации схем компоновки данных 1С (DataCompositionSchema).

## Команда

```bash
java -jar xml-gen.jar skd compile <input.json> <output.xml>
```

**Параметры:**
- `<input.json>` — JSON DSL файл
- `<output.xml>` — выходной Template.xml

## Структура DSL

### Минимальная схема

```json
{
  "dataSets": [
    {
      "name": "НаборДанных1",
      "query": "ВЫБРАТЬ Наименование, Количество ИЗ Номенклатура",
      "fields": [
        {"dataPath": "Наименование"},
        {"dataPath": "Количество"}
      ]
    }
  ]
}
```

### Полная структура

```json
{
  "dataSets": [...],
  "parameters": [...],
  "totalFields": [...],
  "settingsVariants": [...]
}
```

## Наборы данных (dataSets)

### Типы наборов данных

SKD поддерживает три типа наборов данных:

1. **DataSetQuery** — набор данных на основе запроса (самый частый)
2. **DataSetObject** — набор данных на основе объекта
3. **DataSetUnion** — объединение нескольких наборов данных

### DataSetQuery (запрос)

```json
{
  "name": "НаборДанных1",
  "query": "ВЫБРАТЬ ... ИЗ ...",
  "fields": [...]
}
```

### DataSetObject (объект)

```json
{
  "name": "ТаблицаПроверки",
  "objectName": "ТаблицаПроверки",
  "fields": [
    {"dataPath": "Поле1"},
    {"dataPath": "Поле2"}
  ]
}
```

### DataSetUnion (объединение)

```json
{
  "name": "Объединение",
  "items": [
    {
      "name": "Набор1",
      "query": "ВЫБРАТЬ ... ИЗ Таблица1",
      "fields": [...]
    },
    {
      "name": "Набор2",
      "query": "ВЫБРАТЬ ... ИЗ Таблица2",
      "fields": [...]
    }
  ],
  "fields": [...]
}
```

### Базовый синтаксис

```json
{
  "name": "НаборДанных1",
  "query": "ВЫБРАТЬ ... ИЗ ...",
  "fields": [...]
}
```

### Пример набора данных

```json
{
  "dataSets": [
    {
      "name": "Продажи",
      "query": "ВЫБРАТЬ Организация, Номенклатура, Количество, Сумма ИЗ РегистрНакопления.Продажи",
      "fields": [
        {"dataPath": "Организация", "title": "Организация"},
        {"dataPath": "Номенклатура", "title": "Номенклатура"},
        {"dataPath": "Количество", "title": "Количество", "type": "number(15,2)"},
        {"dataPath": "Сумма", "title": "Сумма", "type": "number(15,2)"}
      ]
    }
  ]
}
```

## Поля (fields)

### Базовый синтаксис

```json
{
  "dataPath": "ИмяПоля",
  "title": "Заголовок",
  "type": "тип"
}
```

### Поддерживаемые типы

| DSL тип | 1С тип |
|---------|--------|
| `string` | Строка |
| `string(N)` | Строка(N) |
| `number` | Число |
| `number(D,F)` | Число(D,F) |
| `boolean` | Булево |
| `date` | Дата |
| `CatalogRef.Name` | СправочникСсылка.Name |
| `DocumentRef.Name` | ДокументСсылка.Name |

### Примеры полей

```json
{
  "fields": [
    {"dataPath": "Наименование", "title": "Наименование"},
    {"dataPath": "Количество", "title": "Количество", "type": "number(15,2)"},
    {"dataPath": "Дата", "title": "Дата", "type": "date"},
    {"dataPath": "Организация", "title": "Организация", "type": "CatalogRef.Организации"}
  ]
}
```

## Параметры (parameters)

### Базовый синтаксис

```json
{
  "name": "ИмяПараметра",
  "title": "Заголовок",
  "type": "тип",
  "value": значение
}
```

```json
{

      "name": "Период",

      "title": "Дата начала",

```

## Итоговые поля (totalFields)

### Базовый синтаксис

```json
{
  "dataPath": "ИмяПоля",
  "expression": "Функция(Поле)"
}
```

### Примеры итоговых полей

```json
{
  "totalFields": [
    {"dataPath": "Количество", "expression": "Сумма(Количество)"},
    {"dataPath": "Сумма", "expression": "Сумма(Сумма)"},

  ]
}
```

## Варианты настроек (settingsVariants)

### Базовый синтаксис

```json
{
  "name": "Основной",
  "presentation": "Основной вариант",
  "settings": {
    "selection": [...],
    "filter": [...],
    "order": [...],
    "conditionalAppearance": [...],
    "structure": [...]
  }
}
```

### Selection (выборка полей)

```json
{
  "selection": [
    "Организация",
    "Номенклатура",
    "Количество",
    "Сумма"
  ]
}
```

### Filter (отборы)

**Базовый синтаксис:**
```json
{
  "filter": [
    "Поле оператор значение"
  ]
}
```

**Поддерживаемые операторы:**

| Оператор | Описание |
|----------|----------|
| `=` | Равно |
| `<>` | Не равно |
| `>` | Больше |
| `>=` | Больше или равно |
| `<` | Меньше |
| `<=` | Меньше или равно |
| `in` | В списке |
| `notIn` | Не в списке |
| `contains` | Содержит |
| `filled` | Заполнено |
| `notFilled` | Не заполнено |

**Примеры отборов:**

```json
{
  "filter": [
    "Количество > 0",
    "Сумма >= 1000",
    "Дата >= 2024-01-01T00:00:00",
    "Статус filled",
    "Организация = _"
  ]
}
```

**Автоопределение типов:**
- `true`/`false` → boolean
- `2024-01-01T00:00:00` → dateTime
- Числа → decimal
- Прочее → string

### Order (сортировка)

**Базовый синтаксис:**
```json
{
  "order": [
    "Поле [asc|desc]"
  ]
}
```

**Примеры сортировки:**

```json
{
  "order": [
    "Сумма desc",
    "Организация",
    "Наименование asc"
  ]
}
```

### ConditionalAppearance (условное оформление)

**Базовый синтаксис:**
```json
{
  "conditionalAppearance": [
    {
      "selection": ["Поле1", "Поле2"],
      "filter": ["Условие"],
      "appearance": {
        "Параметр": "Значение"
      },
      "presentation": "Описание"
    }
  ]
}
```

**Параметры оформления:**

| Параметр | Тип значения | Пример |
|----------|--------------|--------|
| `ЦветТекста` | Color | `web:Red`, `style:ПросроченныеДанныеЦвет` |
| `ЦветФона` | Color | `web:LightGray` |
| `Шрифт` | String | `Arial` |
| `Текст` | String | `Не указано` |

**Примеры условного оформления:**

```json
{
  "conditionalAppearance": [
    {
      "selection": ["Сумма"],
      "filter": ["Сумма > 10000"],
      "appearance": {
        "ЦветТекста": "web:Red",
        "Шрифт": "Arial"
      },
      "presentation": "Выделять крупные суммы"
    },
    {
      "filter": ["Статус notFilled"],
      "appearance": {
        "Текст": "Не указано",
        "ЦветТекста": "web:Gray"
      },
      "presentation": "Скрывать пустые статусы"
    }
  ]
}
```

### Structure (группировки)

**Базовый синтаксис:**
```json
{
  "structure": [
    {
      "type": "group",
      "groupBy": ["Поле1", "Поле2"],
      "selection": ["Auto"]
    }
  ]
}
```

**Примеры группировок:**

```json
{
  "structure": [
    {
      "type": "group",
      "groupBy": ["Организация"],
      "selection": ["Auto"]
    },
    {
      "type": "group",
      "groupBy": ["Номенклатура"],
      "selection": ["Количество", "Сумма"]
    }
  ]
}
```

## Использование в 1С

### Создание отчёта

```bsl
Функция СформироватьОтчёт(Параметры)
    СхемаКомпоновкиДанных = ПолучитьМакет("ОсновнаяСхемаКомпоновкиДанных");
    
    НастройкиКомпоновки = СхемаКомпоновкиДанных.НастройкиПоУмолчанию;
    
    // Установить параметры
    НастройкиКомпоновки.ПараметрыДанных.УстановитьЗначениеПараметра("ДатаНачала", Параметры.ДатаНачала);
    НастройкиКомпоновки.ПараметрыДанных.УстановитьЗначениеПараметра("ДатаОкончания", Параметры.ДатаОкончания);
    
    // Скомпоновать
    КомпоновщикНастроек = Новый КомпоновщикНастроекКомпоновкиДанных;
    КомпоновщикНастроек.Инициализировать(Новый ИсточникДоступныхНастроекКомпоновкиДанных(СхемаКомпоновкиДанных));
    КомпоновщикНастроек.ЗагрузитьНастройки(НастройкиКомпоновки);
    
    КомпоновщикМакета = Новый КомпоновщикМакетаКомпоновкиДанных;
    МакетКомпоновки = КомпоновщикМакета.Выполнить(СхемаКомпоновкиДанных, НастройкиКомпоновки);
    
    ПроцессорКомпоновки = Новый ПроцессорКомпоновкиДанных;
    ПроцессорКомпоновки.Инициализировать(МакетКомпоновки);
    
    ПроцессорВывода = Новый ПроцессорВыводаРезультатаКомпоновкиДанныхВТабличныйДокумент;
    ТабличныйДокумент = Новый ТабличныйДокумент;
    ПроцессорВывода.УстановитьДокумент(ТабличныйДокумент);
    ПроцессорВывода.Вывести(ПроцессорКомпоновки);
    
    Возврат ТабличныйДокумент;
КонецФункции
```

## Особенности

### Автоматическая генерация

1. **UUID** — для схемы и всех элементов
2. **Источник данных** — автоматически создаётся "Local"
3. **Вариант по умолчанию** — если не указан, создаётся автоматически
4. **Типы значений** — автоопределение в filter и conditionalAppearance

### Формат файла

- **Без BOM** — Template.xml создаётся без UTF-8 BOM
- **Правильные namespaces** — все необходимые xmlns добавляются автоматически

## Ограничения

### Текущие ограничения (15%)

1. **Только DataSetQuery** — DataSetObject/Union не поддерживаются
2. **Нет CalculatedFields** — вычисляемые поля не поддерживаются
3. **Нет групп условий** — (A AND B) OR C не поддерживается
4. **Базовые флаги** — use, viewMode, userSettingID не поддерживаются

### Workaround

- **DataSetObject/Union** → используй DataSetQuery с запросами
- **CalculatedFields** → используй вычисления в запросах
- **Группы условий** → используй несколько простых условий

### Покрытие use-case

**Реализовано (85%)** покрывает **~90% типичных отчётов:**
- ✅ Отчёты с запросами
- ✅ Отчёты с параметрами
- ✅ Отчёты с итогами
- ✅ Отчёты с отборами
- ✅ Отчёты с сортировкой
- ✅ Отчёты с условным оформлением
- ✅ Отчёты с группировками
