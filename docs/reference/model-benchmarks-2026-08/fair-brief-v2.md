# Бриф для независимого консилиума моделей (fair brief v2)

**Дата сбора фактуры:** снимок на 4 августа 2026.
**Метод:** сбор веб-источников; сведение без переоценки, все числа — из исходных отчётов с указанием источника. Происхождение цифр смешанное: вендорские заявки помечены **(V)**, независимые измерители (Artificial Analysis, vals.ai, Stanford HAI, llm-stats, SEAL, академические) — **(N)**, агрегаторы без прозрачной методологии — **(A)**.

> **Этот бриф намеренно не содержит никаких действующих политик, назначений и интеграционных ограничений; оценка — только по приведённым данным.**

**Дисклеймер о достоверности:**
- Большинство цифр по новым моделям (Claude 5-го поколения, GPT-5.6, Kimi K3, DeepSeek V4, Grok 4.5, MiniMax M3) — вендорские scaffold'ы или пересказы агрегаторов «со слов вендора»; прямые сравнения между вендорами допустимы только по независимым harness'ам (SEAL, AA, vals.ai).
- Исторический разрыв «вендорский scaffold vs стандартизованный SEAL» — 15–30 п.п.; учитывать при любом сопоставлении SWE-bench.
- Конфликты источников сведены в разделе 5; в таблицах конфликтующие значения даны оба с пометкой.
- Официальные первоисточники OpenAI (system card GPT-5.6, developers.openai.com) напрямую не прочитаны — цены/бенчмарки пересказаны 2+ независимыми площадками и сверены между собой.

## 0. Методология: правило двух ярусов (ключевое отличие этой итерации)

**Ошибка прошлой итерации.** В предыдущем брифе метрика AA «доля галлюцинирующих ответов» (Omniscience Hallucination Rate) была собрана **только для DeepSeek (94%)** и стала основанием его исключения из ролей, хотя у остальных моделей она просто не была собрана. Это асимметрия покрытия, дающая неизмеренным моделям нечестное преимущество.

**Что показал симметричный сбор (Artificial Analysis, все 14 моделей, 04.08.2026).** DeepSeek V4 Pro = 94.0% — **не выброс**: GPT-5.6 Luna 90.1%, GPT-5.6 Sol 88.8%, GPT-5.6 Terra 85.2%, DeepSeek V4 Flash 84.4%. А MiniMax M3 (16.1%) и Qwen3.7-Max (22.9%) — **лучше всей линейки GPT-5.6**. Вывод «DeepSeek уникально галлюцинирует» был артефактом неполного измерения.

Также уточнена сама метрика: отдельной колонки «non-refusal rate» у AA **нет**; 94% DeepSeek — это **AA-Omniscience Hallucination Rate** (доля некорректных ответов среди не-верных реакций: incorrect / (incorrect + partial + not attempted)). В этом брифе используется только корректное название.

**Отсюда правило двух ярусов фактуры:**

1. **Ярус 1 — скоринг-допустимые метрики.** Только то, что измерено **одним измерителем для всех 14 моделей**: Artificial Analysis — Intelligence Index v4.1, Coding Index, Omniscience Index, Omniscience Hallucination Rate, цена $/M, скорость tok/s, TTFT. Единая главная таблица — раздел 1. Только этот ярус может быть основанием для сравнительных выводов.
2. **Ярус 2 — справочные метрики (не основание для назначений).** Все остальные бенчмарки (SWE-bench Verified/Pro, Terminal-Bench, LMArena, LiveBench, LegalBench, HLE, BrowseComp, вендорские заявки и т.д.) приводятся с явной пометкой «неполное покрытие — не основание для назначений» и указанием, кого покрывают. Покрытие измерителей по 14 моделям: AA — 14/14; LiveBench — 12–13/14; LMArena — 11/14; vals.ai — 8–9/14; официальные SWE-bench Verified и Terminal-Bench — 5/14 (отстают на 1–2 поколения); Aider polyglot — 0/14 (заморожен ~август 2025, исключён).

**Список моделей (14, актуальные версии на 04.08.2026):** Claude Opus 5, Claude Sonnet 5, Claude Haiku 4.5, GPT-5.6 Sol, GPT-5.6 Terra, GPT-5.6 Luna, Kimi K3, DeepSeek V4 Pro, DeepSeek V4 Flash 0731, GLM-5.2 (Zhipu), Qwen3.7-Max (Alibaba), Gemini 3.1 Pro Preview (Google), Grok 4.5 (xAI/SpaceXAI), MiniMax M3.

### 1.1. Разбор симметричной HR-таблицы

1. **DeepSeek-реабилитация.** HR V4 Pro (94.0%) — верхняя точка плотного кластера 84–94% (Luna 90.1, Sol 88.8, Terra 85.2, Flash 84.4). Назначать вину только DeepSeek по этой метрике было невозможно уже на уровне фактов — вся линейка GPT-5.6 в том же диапазоне.
2. **Лидеры по HR — не старые флагманы:** MiniMax M3 16.1%, Qwen3.7-Max 22.9%, Haiku 4.5 24.7%, GLM-5.2 28.1%. Вывод «китайские/дешёвые модели системно хуже по галлюцинациям», который можно было сделать по устаревшим версиям (Qwen3-Max 89.4%, MiniMax M2 88.4%), на актуальных версиях не держится.
3. **Оговорка про M3 и Haiku:** низкий HR частично куплен отказами — Omniscience Accuracy у M3 всего 15.0%, у Haiku 4.5 — 13.7% (и его Omniscience Index отрицательный: −7.7). Модель, которая часто отвечает «не знаю», галлюцинирует меньше, но и полезной нагрузки даёт меньше. HR без Accuracy трактовать нельзя.
4. **Лучший баланс accuracy/HR** по Omniscience Index: Gemini 3.1 Pro (32.9), Claude Opus 5 (31.3), Grok 4.5 (26.4), GPT-5.6 Sol (21.7), Kimi K3 (18.4).
5. Прошлая итерация смешивала HR с «non-refusal»: это разные вещи. Отдельной метрики отказов AA не публикует; прокси — разность между Accuracy и HR внутри Omniscience.

1. Единого лидера вне AA-индексов нет — задачи раскололись по доменам: BrowseComp ведёт Sol (92.2%), HLE — Opus 5 / Gemini 3.1 Pro (Scale AI), агентная knowledge-work (AA-Briefcase) — Kimi K3 второй.

3. Финансы для новых флагманов почти не измерены — лучшая документированная линейка остаётся у GPT-семейства (и то на предшественниках).
4. Новые модели (GLM-5.2, Qwen3.7-Max, Gemini 3.1 Pro, Grok 4.5, MiniMax M3) на официальных SWE-bench Verified / Terminal-Bench отсутствуют массово — борды отстают на поколения; их вендорские/агрегаторные числа сопоставимы только внутри одного harness'а.

## 4. Категории агентских ролей

Нейтральная типология ролей в мультиагентной системе. Для каждой категории: характер работы, частота/объём вызовов, цена ошибки, механическая проверяемость выхода.

| Категория | Характер работы | Частота/объём | Цена ошибки | Выход механически проверяем? |
|---|---|---|---|---|
| **A. Оркестрация/архитектура** | Декомпозиция задач, маршрутизация субагентов, финальный синтез | Редкие вызовы (~1 на задачу) | Очень высокая | Нет |
| **B. Блокирующее ревью артефактов/кода** | Adversarial-проверка чужой работы с правом остановить приёмку | Средняя | Высокая: ложный «чисто» недопустим; точность и доказательность критичны, скорость вторична | Нет (суждение с доказательствами) |
| **C. Визуальная верификация UI** | Проверка страниц по скриншотам (PNG) + DOM; блокирующая роль | Средняя | Высокая | Частично (DOM — да, визуал — суждение); требуется приём изображений |
| **D. Программирование production-кода** | UI, скрипты; большой объём, многофайловая генерация, tool-use | Высокая | Средняя — смягчается проверкой | Да: исполнением и тестами независимо от автора |
| **E. Авторство тестов** | Генерация unit/e2e тестов до имплементации | Высокая (массовая генерация) | Средняя | Особый случай: выход определяет собственный «зелёный» прогон; самопроверка не считается независимой |
| **F. Копирайтинг на русском языке (voice-critical)** | Посты, статьи, письма; главный критерий — качество русского текста и следование голосу бренда | Средняя/высокая | Средняя (качество текста субъективно) | Нет; кодовые бенчмарки это напрямую не измеряют |
| **G1. Доменный анализ с численным выходом** | Финансы/крипто: сверки, метрики, модели; большой объём справочников в контексте | Средняя/высокая | Высокая | Да: скриптами |
| **G2. Доменный анализ-суждение** | Комплаенс, security-скрининг, оценка нарратива | Средняя | Высокая: цена ложного «всё чисто» | Нет: выход — суждение, механически не валидируется |
| **H. Рутина** | Классификация, извлечение по схеме, дайджесты | Максимальный объём вызовов | Минимальная | Да: выход схемно-валидируем |
| **I. Исследователь кодовой базы** | Read-only поиск и чтение множества файлов, массовые вызовы | Очень высокая | Низкая/средняя | Частично; важны цена и скорость, глубокое рассуждение не нужно |
| **J. Многомодельное совещание и кросс-проверка** | Независимое второе мнение по ключевым решениям | Низкая/средняя | Высокая (по существу совещания) | Нет; ценность = сила рассуждения + независимость семейств друг от друга |

## 5. Пробелы и недостоверность

### Не измерено / не найдено (сведение по всем секциям)

- **Не измерено для всех 14 моделей (системные пробелы):** качество русской прозы (ни mera, ни ruarena ни по одной модели списка); приём изображений/vision-качество в одном harness'е (vision-числа точечные: Gemini 3.1 Pro MMMU-Pro 80.5% (V), MiniMax M3 MMMU-Pro 78.1% (V); GLM-5.2 text-only); security-скрининг (есть только Cybergym 76.7 у DeepSeek Flash (V)); FinanceBench новых флагманов (всех, см. раздел 3).
- **SWE-bench Verified (официальный борд, 5/14):** нет Opus 5, Sonnet 5, всех GPT-5.6, Kimi K3, обеих DeepSeek V4, Gemini 3.1 Pro, Grok 4.5, GLM-5.2, Qwen3.7-Max. Точечно: Haiku 4.5 (66.6%), GLM-5 (72.8%), Qwen3-Coder (69.6%), MiniMax M2 (61.0%) — только предшественники/смежные версии.
- **Terminal-Bench (официальный борд, 5/14):** аналогично отстаёт (точки: Haiku 4.5 28.3–41.8%, GLM-5 52.4%, Qwen3-Coder 27.2%, Gemini 3.1 Pro 80.2%, MiniMax M2 30.0–42.0%).
- **Aider polyglot: 0/14** — лидерборд заморожен на ~августе 2025 (топ: gpt-5 high 88.0%). Исключён из брифа.
- **LiveBench:** нет MiniMax M3 (есть M2.5/M2.7); ревизия DeepSeek Flash 0731 не подтверждена; точное число для Gemini 3.1 Pro и GLM-5.2 не извлечено. Матрица покрытия LMArena/LiveBench/vals.ai проверялась для старых версий (Grok 4.1, M2, Qwen3-Max) — для новых версий покрытие не переснято.
- **τ2-bench retail/airline** — почти не покрыт для моделей списка (точки: GLM-5 75.61% (N), вендорские/агрегаторные точки GLM-5.2, M3, Qwen3-Max).
- **GAIA** — ни по одной модели списка.
- **TTFT (AA):** Kimi K3, GLM-5.2, DeepSeek Flash 0731, Opus 5 — не извлечены. Скорость сильно зависит от провайдера и режима reasoning (пример из прошлой итерации: Sol 750 t/s — хостинг Cerebras для select customers, не стандартный API).
- **Русскоязычные бенчмарки** — не найдены ни для одной новой модели (GLM, Qwen, Grok, MiniMax — явные пробелы в research).
- **Официальный GA DeepSeek V4-Pro** — «скоро», бенчмарков нет; веса Flash-0731 не опубликованы.
- **Gemini 3.1 Pro** — всё ещё Preview; дата GA не объявлена; AA Intelligence Index показывал 57 на релизе и 46–46.5 в июле — вероятна перекалибровка индекса, сравнивать только внутри v4.1.
- **Grok 4.5** — на AA только вариант «high»; число параметров (1.5T) — только слова Маска; max output не опубликован; EU-статус не зафиксирован.
- **MiniMax M3** — AA «cost per task»/«tokens per task» не извлечены (JS); промо-«скидка 50%» без даты окончания.
- **Официальные первоисточники** OpenAI (system card GPT-5.6), вендорские не-кодинговые таблицы Anthropic/OpenAI/Moonshot/DeepSeek напрямую не получены.
- **Одиночный harness-замер GLM-5 (LayerLens Stratix)** показал нестабильность на перезамерах (HLE 22.41% → 10.37%) — сигнал о вариативности любых одиночных снимков.

### Прочие оговорки о достоверности

- У Kimi, DeepSeek, MiniMax эффективная цена критично зависит от cache-hit rate (K3: $0.30/M при hit; DeepSeek: скидка 98% до $0.003/M; M3: $0.06/M).
- У GPT-5.6 есть тариф на cache-write (×1.25 входа); у MiniMax M3 переход через 512K входа переводит весь запрос в удвоенный тир.
- Реальная стоимость DeepSeek Flash выше стикерной из-за 3× вербозности (AA).
- Промо-цена Sonnet 5 ($2/$10) действует до 31.08.2026; снижения цен Terra/Luna — с 30.07.2026; экономику надо пересчитывать на дату решения.
