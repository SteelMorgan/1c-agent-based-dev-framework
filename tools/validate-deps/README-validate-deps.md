# Валидатор зависимостей фреймворка

## Назначение

Скрипт `validate-framework-deps.py` проверяет корректность зависимостей между артефактами фреймворка (навыки, правила, агенты, воркфлоу).

## Что проверяется

### 1. Существование зависимостей
Все пути в `depends_on:[]` должны указывать на существующие файлы.

### 2. Полнота декларации зависимостей
Если в тексте документа упоминается другой артефакт фреймворка (через markdown-ссылку или прямое упоминание пути), он должен быть задекларирован в `depends_on:[]`.

**Паттерны поиска:**
- Markdown-ссылки: `[текст](framework/...)`
- Прямые упоминания: `framework/skills/...`, `framework/rules/...`

### 3. Навыки агентов
Для агентов проверяется, что все навыки из поля `skills:[]` существуют и (опционально) задекларированы в `depends_on:[]`.

### 4. Взаимозависимости (не ошибка)
Обнаруживает группы компонентов, связанных циклическими зависимостями (SCC — strongly connected components). Это **информационное сообщение**, не ошибка. Взаимозависимые компоненты — нормальная ситуация (например, правила TDD и Cross-Review ссылаются друг на друга).

## Использование

### Базовая проверка

```bash
python3 tools/validate-framework-deps.py
```

### Автоматическое исправление

```bash
python3 tools/validate-framework-deps.py --fix
```

Автоматически добавляет недостающие зависимости в `depends_on:[]` для предупреждений.

### Экспорт взаимозависимостей

```bash
python3 tools/validate-framework-deps.py --export-cycles tools/framework-cycles.json
```

Генерирует JSON с группами взаимозависимостей для использования в `install.py`.

## Типы сообщений

### ❌ Ошибки (exit code 1)
- Несуществующие файлы в `depends_on`
- Несуществующие навыки в `skills`

### ⚠️ Предупреждения (exit code 0)
- Упоминания артефактов в тексте без декларации в `depends_on`
- Навыки агентов не в `depends_on` (опционально)

### 💡 Информация (exit code 0)
- Группы взаимозависимых компонентов

## Примеры проблем

### Проблема 1: Несуществующая зависимость

**Найдено:**
```
framework/subagents/developer.md: зависимость не существует: framework/rules/missing.md
```

**Решение:**
Убрать несуществующий путь из `depends_on:[]` или создать файл.

### Проблема 2: Недекларированная зависимость

**Найдено:**
```
framework/rules/framework-bootstrap/SKILL.md: упоминается 
framework/rules/mandatory-tools.md, но не задекларировано в depends_on
```

**Решение:**
Добавить в frontmatter:
```yaml
depends_on:
  - framework/rules/mandatory-tools.md
```

Или запустить `--fix` для автоматического исправления.

## Алгоритм поиска взаимозависимостей

Используется алгоритм Тарьяна для поиска strongly connected components (SCC) в графе зависимостей. Группа — это множество узлов, где каждый достижим из каждого. Возвращаются только нетривиальные SCC (≥ 2 узлов).

## Интеграция в CI/CD

```yaml
- name: Validate framework dependencies
  run: python3 tools/validate-framework-deps.py
```

## Ограничения

1. **Не проверяет семантику** — только структурную корректность ссылок
2. **Не различает типы зависимостей** — все зависимости равнозначны
3. **Не проверяет транзитивные зависимости** — только прямые

## Расширение

Для добавления новых проверок:

1. Добавьте метод `check_*` в класс `FrameworkValidator`
2. Вызовите его в методе `run()`
3. Добавьте ошибки/предупреждения в `self.errors` / `self.warnings`
