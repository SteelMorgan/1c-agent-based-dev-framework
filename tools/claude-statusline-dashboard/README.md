# Claude Code statusline — мини-дашборд

Bash-скрипт для `statusLine.command` в `~/.claude/settings.json`. Превращает однострочный статус Claude Code в компактный многострочный дашборд с лимитами Claude и Codex.

## Как выглядит

```
context: ▆▆▆▆▆▆▆▆▆▆▆▆▆▆▂▂▂▂▂▂  72%   ⚠  Opus 4.7 (1M) · high  · [master *]
⠀
         Claude   [x0.8]                                │  Codex   [x0.3]        1d    ago
5h:      ▆▆▂▂▂▂▂▂▂▂▂▂▂▂▂▂▂▂▂▂  8%    in 1h     │  ▆▆▂▂▂▂▂▂▂▂▂▂▂▂▂▂▂▂▂▂  10%   now
7d:      ▆▆▆▆▆▆▆▆▆▆▆▆▆▆▂▂▂▂▂▂  70%   in 18h    │  ▆▆▆▂▂▂▂▂▂▂▂▂▂▂▂▂▂▂▂▂  15%   in 3d
```

В терминале цвета пастельные:

- `<50 %` — мягкий мятный
- `50..79 %` — мягкий персиковый
- `>=80 %` — мягкий коралловый

## Структура вывода

| Строка | Содержимое |
|--------|-----------|
| 1 | `context: <бар> <%>  [⚠]  <модель> · <effort>  · <git>` |
| 2 | пустая (Braille `⠀`, чтобы рендер не схлопывал) |
| 3 | `         Claude [xK]                                │  Codex [xK]  <freshness>` |
| 4 | `5h:  <claude бар> <%> <delta>  │  <codex бар> <%> <delta>` |
| 5 | `7d:  <claude бар> <%> <delta>  │  <codex бар> <%> <delta>` |

### Контекст-предупреждение `⚠`

- `>= 70 %` или `>= 300 000` токенов — жёлтый
- `>= 80 %` или `>= 400 000` токенов — красный

### Pace-коэффициент `[xK]`

Скорость сжигания недельного лимита: `K = pct_used × WEEK / (elapsed × 100)`.

- `K < 0.9` — мятный, есть запас
- `0.9..1.1` — персиковый, впритык
- `K > 1.1` — коралловый, сгорим раньше резета

### Codex freshness

`Codex [xK]` стоит над codex-баром, справа от него — возраст последней сессии Codex CLI:

- `live` (< 30 мин)
- `Nh ago`, `Nd ago`

Цифра возраста выравнена под колонку `%` строк 5h/7d, слово `ago` — под колонку delta (`now`, `in 3d`).

## Источники данных

| Что | Откуда |
|-----|--------|
| Контекст, модель, effort, лимиты Claude | stdin JSON от Claude Code |
| Лимиты Codex (5h + 7d, resets_at) | `~/.codex/sessions/*/*/*/rollout-*.jsonl`, поле `rate_limits` |
| Git-ветка и dirty-маркер | `git -C <cwd> symbolic-ref` + `status --porcelain` |

Если в `~/.codex/sessions` нет файла моложе 14 дней — правая колонка не выводится.

## Side-effect

После парсинга пишет `${TMPDIR:-/tmp}/claude-ctx-state.json`:

```json
{"pct":72,"tokens":720000,"limit":1000000}
```

Используется RLM `context-monitor.sh` hook для авто-сохранения сессии при заполнении контекста.

## Установка

1. Скопировать `statusline.sh` в любое место (например, `~/.claude/statusline-command.sh`).
2. `chmod +x` на файл.
3. В `~/.claude/settings.json`:

```json
{
  "statusLine": {
    "type": "command",
    "command": "/home/<user>/.claude/statusline-command.sh"
  }
}
```

4. Зависимости: `bash`, `jq`, `git`, `awk`, `grep`. Без них правая колонка / git / pace тихо выпадают.

## Тонкости отрисовки

- `×` (U+00D7) убран в пользу ASCII `x` — у `×` East Asian Width = Ambiguous, и Claude Code TUI рендерит его как 2 ячейки, ломая выравнивание.
- Пустая строка-разрыв сделана через `⠀` (U+2800 Braille Pattern Blank) — рендер схлопывает чистый `\n`.
- Бары используют bottom-anchored блоки `▆/▂` — между рядами 5h и 7d остаётся вертикальный зазор и они не сливаются в один «толстый» бар.

## Кастомизация

| Что | Где |
|-----|-----|
| Ширина бара (20 ячеек) | вызовы `bar "$pct" 20` |
| Палитра пастельных тонов | блок `# === Colours ===` |
| Пороги pace `K` (0.9 / 1.1) | функция `pace_color` |
| Пороги warning `⚠` (70 % / 80 %, 300k / 400k) | блок `# --- Row 1` |
| Где живут Codex-сессии | переменная `codex_session` |
