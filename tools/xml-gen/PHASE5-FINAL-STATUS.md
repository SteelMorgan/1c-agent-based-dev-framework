## Что можно делать с текущей реализацией

### ✅ Полностью поддерживается

**Типичный отчёт:**
```json
{
  "dataSets": [{
    "name": "Продажи",
    "query": "ВЫБРАТЬ Организация, Номенклатура, Количество, Сумма ИЗ Продажи",
    "fields": [
      {"dataPath": "Организация", "title": "Организация"},
      {"dataPath": "Номенклатура", "title": "Номенклатура"},
      {"dataPath": "Количество", "title": "Количество", "type": "number(15,2)"},
      {"dataPath": "Сумма", "title": "Сумма", "type": "number(15,2)"}
    ]
  }],
  "parameters": [
    {"name": "Период", "type": "StandardPeriod", "value": "LastMonth"}
  ],
  "totalFields": [
    {"dataPath": "Количество", "expression": "Сумма(Количество)"},
    {"dataPath": "Сумма", "expression": "Сумма(Сумма)"}
  ],
  "settingsVariants": [{
    "name": "Основной",
    "presentation": "Продажи по организациям",
    "settings": {
      "selection": ["Организация", "Номенклатура", "Количество", "Сумма"],
      "filter": [
        "Количество > 0",
        "Дата >= 2024-01-01T00:00:00"
      ],
      "order": ["Сумма desc", "Организация"],
      "conditionalAppearance": [{
        "selection": ["Сумма"],
        "filter": ["Сумма > 10000"],
        "appearance": {"ЦветТекста": "web:Red"},
        "presentation": "Выделять крупные суммы"
      }],
      "structure": [{
        "type": "group",
        "groupBy": ["Организация"],
        "selection": ["Auto"]
      }]
    }
  }]
}
```

**Результат:** Полностью рабочий Template.xml для 1С

### ❌ Не поддерживается (редкие случаи)

1. **DataSetObject** — наборы данных на основе объектов метаданных
2. **DataSetUnion** — объединение нескольких наборов данных
3. **CalculatedFields** — вычисляемые поля в схеме
4. **Сложные группы условий** — (A AND B) OR (C AND D)

**Workaround:** Эти возможности можно реализовать через запросы в DataSetQuery
