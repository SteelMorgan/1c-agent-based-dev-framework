## Реализовано

### 1. JSON DSL для табличных документов (`MxlDsl.java`)

Структура данных для описания макетов SpreadsheetDocument:

```java
- columns: Integer              // Количество колонок
- defaultWidth: Integer         // Ширина колонок по умолчанию
- columnWidths: Map             // Ширины колонок {"1": 15, "2-8": 40}
- fonts: Map<String, Font>      // Именованные шрифты
- styles: Map<String, Style>    // Именованные стили
- areas: List<Area>             // Именованные области
```

**Вложенные классы:**
- `Font` — шрифт (face, size, bold, italic, underline, strikeout)
- `Style` — стиль (font, align, valign, border, borderWidth, wrap, format)
- `Area` — область (name, rows)
- `Row` — строка (height, rowStyle, cells, empty)
- `Cell` — ячейка (col, span, rowspan, style, param, detail, text, template)

### 2. Генератор табличных документов (`MxlWriter.java`)

**Основной функционал:**
- Генерация Template.xml в формате Designer
- Поддержка областей (areas) с именами
- Поддержка текстовых ячеек (text)
- Поддержка параметров (param)
- Поддержка шаблонов (template)
- Объединение ячеек по горизонтали (span → merge)
- Объединение ячеек по вертикали (rowspan → rowMerge)
- Настройки языка (languageSettings)
- Ширина колонок (defaultWidth)

**Технические детали:**
- Без BOM для Template.xml (согласно спецификации 1С)
- Индексы строк 0-based
- Индексы колонок 0-based в XML (1-based в DSL)
- templateMode=true для всех макетов
- Автоматический подсчёт общего количества строк (height, vgRows)

### 3. CLI команда `mxl compile`

```bash
java -jar xml-gen.jar mxl compile <input.json> <output.xml> [--format designer|edt]
```

**Пример:**
```bash
java -jar xml-gen.jar mxl compile template.json Template.xml
```

## Ограничения текущей реализации

### 1. Шрифты и стили не реализованы

Поля `fonts` и `styles` в DSL определены, но не обрабатываются в `MxlWriter`.

**Причина:** Требует реализации палитр форматов (format palette) и индексов форматов для каждой ячейки.

### 2. Ширины колонок упрощены

Поддерживается только `defaultWidth` для всех колонок. Поле `columnWidths` игнорируется.

**Причина:** Требует парсинга диапазонов ("2-8", "5,7,9") и генерации индивидуальных элементов `<column>`.

### 3. rowStyle не реализован

Автозаполнение пустых ячеек стилем строки не работает.

**Причина:** Требует сложной логики отслеживания rowspan из предыдущих строк.

### 4. Нет поддержки сложных элементов

Не поддерживаются:
- Рисунки (штрихкоды, картинки)
- Фон ячеек (backColor)
- Примечания (notes)
- Множественные наборы колонок (columnsID)
- Области типа Columns / Rectangle

### 5. EDT формат не реализован

`MxlWriter.create()` для EDT выбрасывает `UnsupportedOperationException`.

### 6. Нет валидации DSL

Не проверяется корректность:
- Индексы колонок (col) в пределах columns
- Уникальность имён областей
- Корректность span/rowspan

## Пример использования

### JSON DSL:

```json
{
  "columns": 3,
  "defaultWidth": 50,
  "areas": [
    {
      "name": "Заголовок",
      "rows": [
        {
          "cells": [
            {"col": 1, "span": 3, "text": "Тестовый документ"}
          ]
        }
      ]
    },
    {
      "name": "ШапкаТаблицы",
      "rows": [
        {
          "cells": [
            {"col": 1, "text": "№"},
            {"col": 2, "text": "Наименование"},
            {"col": 3, "text": "Количество"}
          ]
        }
      ]
    },
    {
      "name": "Строка",
      "rows": [
        {
          "cells": [
            {"col": 1, "param": "НомерСтроки"},
            {"col": 2, "param": "Товар"},
            {"col": 3, "param": "Количество"}
          ]
        }
      ]
    }
  ]
}
```

### Генерация:

```bash
java -jar xml-gen.jar mxl compile template.json Template.xml
```

### Результат:

Корректный Template.xml с:
- Настройками языка (ru)
- 3 колонками
- 3 областями (Заголовок, ШапкаТаблицы, Строка)
- Объединением ячеек (span=3 → merge=2)
- Параметрами заполнения
- templateMode=true
- Без BOM
