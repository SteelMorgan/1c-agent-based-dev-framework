## Что можно делать прямо сейчас

### ✅ Полностью поддерживается

**Генерация метаданных 1С:**
```bash
# Внешняя обработка
java -jar xml-gen.jar epf init MyProcessor

# Форма
java -jar xml-gen.jar form compile form.json Form.xml

# Табличный документ
java -jar xml-gen.jar mxl compile template.json Template.xml

# Схема компоновки данных
java -jar xml-gen.jar skd compile schema.json Template.xml

# Роль
java -jar xml-gen.jar role compile role.json Role.xml
```

**Типичные отчёты:**
- Отчёты с запросами к данным
- Отчёты с параметрами (период, организация и т.д.)
- Отчёты с итоговыми полями (суммы, количества)
- Отчёты с отборами (>, <, =, filled и т.д.)
- Отчёты с сортировкой
- Отчёты с условным оформлением (цвета, шрифты)
- Отчёты с группировками

### ⏸️ Отложено (редкие случаи)

- Отчёты с объединением наборов данных (DataSetUnion)
- Отчёты с наборами данных на основе объектов (DataSetObject)
- Отчёты с вычисляемыми полями (CalculatedFields)
- Отчёты со сложными группами условий ((A AND B) OR C)

**Workaround:** Эти возможности можно реализовать через запросы в DataSetQuery
